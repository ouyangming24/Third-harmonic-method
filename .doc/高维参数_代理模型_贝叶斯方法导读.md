# 高维参数反演、代理模型与贝叶斯方法（导读）

面向 3ω / 热物性等多参数非线性拟合场景，说明工业界与学术界常说的「高维参数」「代理模型」「贝叶斯」等概念分别是什么、解决什么问题、**不能**解决什么问题，以及和传统最小二乘 / 粒子群的关系。

---

## 1. 先分清三类问题

| 说法 | 实际在做什么 | 典型输出 |
|------|----------------|----------|
| **点估计拟合** | 找一组参数使残差最小 | \(\hat{\theta}\)（一个点） |
| **不确定度 / 后验推断** | 问「哪些参数合理、置信多少」 | 区间、协方差、后验分布 |
| **加速正演** | 正演太贵，先训一个快模型再优化 | 近似 \(f(\theta)\approx \tilde f(\theta)\) |

新闻里的「AI 拟合上百参数」，往往是三者组合，而不是「大模型直接猜物理量」。

---

## 2. 高维参数（High-dimensional parameters）

### 2.1 什么叫「高维」

反问题里，参数向量 \(\theta\in\mathbb{R}^d\)：

- \(d\sim 2\sim 10\)：常见 3ω（\(\kappa\)、\(C_p\)、接触热阻、几何修正等）
- \(d\sim 20\sim 100+\)：聚变输运剖面、气候、全装置标定、材料本构场离散后的自由度

**维数灾难**：网格点数随 \(d\) 指数增长，随机撒点、粒子群在高维会极慢且不可靠。

### 2.2 关键认识：名义维数 ≠ 有效维数

「上百参数」很少意味着数据能独立约束 100 个自由度。常见情况是：

1. **不可辨识**：多个参数组合给出几乎相同的曲线（如 \(\kappa\) 与 \(\rho C_p\)、镀层与芯）。
2. **强先验 / 正则**：大部分参数被物理约束或惩罚项钉死，真正自由的只有低维组合。
3. **降维**：用 PCA、自编码器、稀疏表示，把 \(\theta\) 压到有效坐标 \(z\in\mathbb{R}^{d_{\mathrm{eff}}}\)，\(d_{\mathrm{eff}}\ll d\)。

因此：**高维方法的核心往往是「降维 + 先验」，不是「维数越高越适合 AI」。**

### 2.3 对 3ω 的含义

纤维 / 薄膜 3ω 通常有效自由度并不高。瓶颈多半是：

- 可辨识性（敏感度、相关矩阵）
- 系统误差（几何、接触、辐射）
- 信噪比与频段选择  

而不是缺少「能吃下 100 维」的算法。

---

## 3. 代理模型（Surrogate / Metamodel）

### 3.1 动机

完整正演 \(y = f(\theta)\) 若很贵（有限元、MHD、分子动力学）：

- 每次优化或 MCMC 要调用成百上千次 \(f\)
- 算不动 → 先造一个**便宜近似** \(\tilde f(\theta)\approx f(\theta)\)

### 3.2 常见形式

| 类型 | 思路 | 备注 |
|------|------|------|
| 多项式 / 响应面 | 局部泰勒或全局多项式 | 维数低时好用 |
| **高斯过程 (GP)** | 数据点之间插值 + 不确定度 | 贝叶斯优化常用；高维样本需求大 |
| **神经网络 / 算子学习** | 用仿真库监督学习 | 换工况要重训或迁移 |
| 降阶模型 (ROM) | POD、本征正交等 | 保留部分物理结构 |

### 3.3 代理模型**不是**什么

- 不是取消物理模型：训练集仍来自物理正演或实验。
- 不是自动给出「真实 \(\kappa\)」：代理错了，优化会精致地错。
- 不是大语言模型：这里的「神经网络」是函数逼近器。

### 3.4 何时值得用（对 3ω）

- 正演已经很快（解析 / 半解析 Olson、纤维 \(F(m)\)）→ **通常不需要**代理。
- 正演变成 3D FEM、多物理场耦合、要扫大量设计 → 才考虑代理。

一句话：**代理解决「算得起」，不解决「辨识得出」。**

## 4. 贝叶斯方法（Bayesian inference）

### 4.1 和最小二乘的差别

最小二乘（含 TRF、LM、不少 PSO 用法）找：

\[
\hat\theta = \arg\min_\theta \| y_{\mathrm{exp}} - f(\theta) \|^2
\]

贝叶斯写：

\[
p(\theta\mid y) \propto p(y\mid\theta)\, p(\theta)
\]

- \(p(y\mid\theta)\)：似然（数据有多吻合模型）
- \(p(\theta)\)：先验（物理边界、文献经验）
- \(p(\theta\mid y)\)：后验（拟合后参数的概率分布）

点估计 \(\hat\theta\) 只是后验的一个摘要（均值 / MAP）；更重要的是**宽度与形状**（不确定度、多峰、退化方向）。

### 4.2 常用算法

| 方法 | 作用 | 高维时 |
|------|------|--------|
| MCMC（Metropolis、HMC/NUTS） | 采后验样本 | \(d\) 大时变慢，需好先验 |
| 变分推断 (VI) | 用简单分布近似后验 | 更快，可能偏乐观 |
| 集成卡尔曼 / 变分同化 | 状态+参数联合估计 | 地球科学、数字孪生常用 |
| **贝叶斯优化 (BO)** | 用 GP 选下一组 \(\theta\) 去评估 | 面向「黑箱优化」，不是完整后验 |

注意：新闻里「贝叶斯」有时指 **BO（少试验调参）**，有时指 **完整贝叶斯反演**；二者不同。

### 4.3 贝叶斯能替你做什么

- 自动给出参数不确定度（部分替代手工「±20% 敏感度扫」）
- 先验里编码边界与物理知识（比硬截断更柔和）
- 后验若很扁或香蕉形 → 直接暴露**不可辨识**

### 4.4 贝叶斯**不能**替你做什么

- 先验乱写 → 后验跟着错
- 模型结构错（该用 \(F(m)\) 却用一阶模态）→ 后验会「自信地错」
- 不替代实验设计：频段、几何仍决定信息量

## 5. 三者如何拼在一起（大科学常见流水线）

以「贵正演 + 较多参数」为例（聚变、航空数字孪生常类似）：

```
物理正演 f(θ) 很贵
        │
        ▼
用仿真库训练代理模型  f̃(θ)
        │
        ▼
在 f̃ 上做贝叶斯优化 / MCMC / 变分推断
        │
        ▼
有效参数往往经降维 / 稀疏先验压到低维
        │
        ▼
输出：参数估计 + 不确定度 +（可选）下一组该测什么
```

这才是新闻「AI 拟合几十上百参数」的常见技术内核，而不是「把 CSV 丢给 ChatGPT」。

## 6. 和其他关键词的对照

| 名词 | 一句话 |
|------|--------|
| 粒子群 / 遗传 / 差分进化 | 全局**点估计**搜索；不天然给不确定度 |
| TRF / LM / `least_squares` | 局部（或信赖域）最小二乘；快，依赖初值 |
| 多起点拟合 | 多个初值跑局部优化，减轻初值敏感 |
| 敏感度 / 可辨识性分析 | 问「数据能不能约束该参数」 |
| 主动学习 / 最优实验设计 | 问「下一组频率/工况信息量最大」 |
| PINN / 神经算子 | 把方程与数据写进网络；热丝 3ω 上未成计量主流 |
| 大语言模型 | 适合写代码、解释残差；不适合当 κ 的计量来源 |

## 7. 和本仓库 3ω 工作的对应建议

| 需求 | 更匹配的方向 | 通常不必上 |
|------|----------------|------------|
| 纤维 / 薄膜解析正演已很快 | 多起点 TRF + 相关/敏感度报告 | 深度代理网络 |
| 想少拍脑袋设初值 | 全局初值搜索或拉丁超立方多起点 | 「端到端 AI」 |
| 想报不确定度 | 剖面似然、bootstrap、或轻量贝叶斯 | 聚变级 MCMC 集群 |
| 参数一多就飘 | 固定部分参数、可辨识性筛查、正则 | 盲目增加自由参数 |
| 正演将来变成重 FEM | 再考虑代理 + BO | 现在过度工程 |

**原则**：先进方法优先自动化**诊断与不确定度**；物理模型、边界与实验质量仍要人负责验收。

## 8. 极简公式备忘

**最小二乘**

\[
\hat\theta=\arg\min_\theta\sum_i w_i\bigl(y_i-f_i(\theta)\bigr)^2
\]

**贝叶斯后验**

\[
p(\theta\mid y)\propto \exp\Bigl(-\tfrac12\|y-f(\theta)\|_W^2\Bigr)\,p(\theta)
\]

**代理**

\[
f(\theta)=\tilde f(\theta)+\varepsilon_{\mathrm{model}}(\theta)
\]

优化/推断在 \(\tilde f\) 上进行时，必须评估 \(\varepsilon_{\mathrm{model}}\) 是否可接受。

---

## 9. 一句话总结

- **高维参数**：名义自由度可以很大，有效可辨识自由度通常很小；关键是降维与先验。  
- **代理模型**：正演太贵时的快照近似；解决算力，不解决可辨识。  
- **贝叶斯**：把拟合从「一个点」升级为「分布 + 不确定度」；仍依赖模型与先验。  
- **AI 新闻**：多为代理 + 优化/推断的工程化，不是免模型、免人工的万能拟合。

对当前 3ω 程序：把「多起点 + 自动可辨识/不确定度报告」做扎实，通常比追「上百参数 AI」更有回报。
