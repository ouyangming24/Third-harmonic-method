## 1. 「绝缘 PI 独立传感器」

石墨层 **导电**，若把金属加热线直接做在石墨上，会与样品短路，无法按经典 3ω 读 \(V_{3\omega}\)。

独立传感器方案要点：

1. 加热/测温线做在 **绝缘 PI 膜** 上（或封装在 PI 中），与石墨 **电隔离**。
2. 传感器与石墨表面用 **导热脂 / 压合** 形成热接触，热流经界面进入石墨层。
3. 拟合时按 **多层结构** 建模：传感器层（PI±金属线热容）→ 界面热阻 \(R_c\) → 石墨层 → 基底（若有）。

本方案测的是「传感器–界面–石墨–基底」的 **复合热响应**；石墨 \(k\) 的可辨识性取决于频段内热穿透深度是否主要「看见」石墨层，以及界面热阻是否可控、可标定。

**PI 厚度定制：** 标准厚 PI（如 ~25 µm）自身交叉热阻 \(H_{\mathrm{PI}}/k_{\mathrm{PI}}\) 往往可与界面 \(R_c\)、石墨层热阻同量级甚至更大。若石墨预期 \(k\) 偏高、或界面 \(R_c\) 已不小，厚 PI 会把样品贡献「压扁」。因此本测试 **不沿用默认厚膜**，而是根据预估石墨 \(k\) 与可达 \(R_c\)，**制作更薄的 PI 独立传感器**，使 \(H_{\mathrm{PI}}/k_{\mathrm{PI}}\) 明显小于（或至少可与）石墨有效热阻与 \(R_c\) 可比，提高对石墨 \(k\) 的灵敏度。薄 PI 需兼顾：机械强度、绝缘可靠性、制线工艺与压合平整度。

粗判（量级）：希望 \(H_{\mathrm{PI}}/k_{\mathrm{PI}} \lesssim R_c + H_g/k_g\)（或至少不过分大于右侧）；石墨 \(k\) 越高、\(R_c\) 越大，越应把 PI 做薄，并同步把脂层/接触做薄、做稳。

## 3. 推荐层结构（拟合 GUI 自上而下）

GUI 约定：**第 0 层 = 最靠加热器一侧**，基底在最后一层。

### 方案 A：有导热脂的压合测量

```
[加热线（传感器参数里单独建模）]
    ↓
层0: PI（传感器衬底）          — k、ρ、c、H 尽量用标定/已知值固定
层1: 导热脂 / 等效接触层       — H 薄；可拟合 Rc 或等效 k
层2: 石墨层                    — **主要拟合目标：k_y**（必要时 ρc）
层3: 基底（Si / 玻璃 / …）     — k、H 尽量已知固定
```

### 方案 B：无脂干压（仅当表面极平、压强可控）

```
层0: PI
层1: 石墨（界面用层间 Rc 描述）
层2: 基底
```

接触差时 \(R_c\) 会吞掉石墨信号，**优先方案 A + 压力可重复**。

## 4. 频率与穿透深度（选频依据）

热穿透深度量级：

\[
\delta \sim \sqrt{\frac{\alpha}{2\omega}},\quad \omega=2\pi f_{\mathrm{电}},\quad \alpha=\frac{k}{\rho c}
\]

选频原则（定性）：

1. **高频**：\(\delta\) 浅，主要敏感 PI / 脂 / 近表面界面；用于约束传感器与界面。
2. **中频**：\(\delta\) 进入石墨层厚度量级，**对石墨 \(k\) 最敏感**。
3. **低频**：\(\delta\) 深至基底，敏感基底与整体半无限假设；用于约束基底或检验模型。

实验前用文献 \(\alpha\) 粗算 \(\delta(f)\)，使扫频覆盖「浅 → 穿过石墨 → 进入基底」三段；测完再用拟合残差微调频段。

| 频段 | 建议电频率量级（按样品改） | 目的 |
|------|---------------------------|------|
| 高 | 数百 Hz～数 kHz | 传感器 / 脂 / 界面 |
| 中 | 数十～数百 Hz | 石墨层 |
| 低 | 数 Hz～数十 Hz | 基底 / 有限厚度效应 |

线宽约束：线源近似大致要求 \(\delta \gtrsim\) 数倍 \(b\)；基底半无限大致要求 \(\delta \ll H_{\mathrm{substrate}}\)。不满足时 **不要用斜率法**，用 GUI 多层全模型拟合。

## 5. 锁相与等待（与当前 GUI 一致）

| 设置 | 含义 | 建议起步 |
|------|------|----------|
| τ 系数 | \(\tau = \text{系数}/f\) | 默认 5 |
| 自动等待倍数 | 等待 \(= N\times\tau\)（4 阶滤波） | 建议 **8～10**（比默认 5 更稳） |
| 手动固定等待 | 特殊频点或调试 | 低频可单独加长 |

注意：默认「系数 5 + 倍数 5」→ \(\tau=5/f\)，等待 \(=25/f\)，**不是**等待也等于 \(5/f\)。

激励：先小电压扫一遍看 \(V_1/V_3\) 信噪比，再略增功率；避免石墨或脂层过热、界面漂移。

## 6. 实验流程

### 0 — 准备与标定

1. 按预估石墨 \(k\) 与目标/可达 \(R_c\) **选定并制作更薄 PI 传感器**；实测 \(H_{\mathrm{PI}}\)，确认绝缘与压合平整度可接受。
2. 目视检查：线完整、焊点牢固、无短路。
3. **TCR 标定**：恒温台多温度点测 \(R(T)\)，得到 \(\alpha_R\)（或 \(dR/dT\)），写入 GUI。
4. 四线测室温 \(R\)；记录 \(b,L\)（显微镜/设计值）。
5. 石墨厚度与基底参数录入表格（§2）。
6. 准备参考样（无石墨或标准块）与待测样；导热脂同批、同用量习惯。

### 1 — 参考 / 传感器自洽

1. 传感器压在参考结构上（同脂、同压）。
2. 扫频采集 \(V_{1\omega},V_{3\omega}\)（幅相或实虚部）。
3. 拟合：固定已知层，主要检验 **PI + 脂 + \(R_c\)** 是否与模型一致；必要时微调脂厚 / \(R_c\) / 传感器热容。
4. 保存：原始 xlsx/csv + 层配置 + 拟合结果；记为 **Run-Ref**。

### 2 — 石墨样品正式测量

1. 清洁接触面；涂脂（尽量与 Ref 同厚度习惯）；夹具压强与 Ref 一致。
2. 同传感器、同输出电压、同频点表扫频（可略加密中频）。
3. 建议重复 **≥2～3 次**（每次重新压合），评估接触重复性。
4. 保存：`Run-G-01…`；备注温度、湿度、压强、脂批次。

### 3 — 数据分析与复核

1. 导入数据 → 按 §3 建层 → 拟合目标优先 **石墨 \(k_y\)**。
2. 固定策略（推荐顺序）：
   - 固定：PI 的 \(k,\rho,c,H\)（用 Ref 结果）、基底物性与厚度；
   - 固定或窄范围：脂层厚度（用 Ref）；
   - 可拟合：石墨 \(k_y\)；必要时石墨–脂 \(R_c\)、石墨 \(\rho c\)（一次勿放开过多参数）。
3. 对比：Amplitude / Phase / Real+Imag 多目标是否一致。
4. 敏感度检查：脂厚 ±20%、\(R_c\) 量级变化时，\(k_g\) 漂移多少 → 写入不确定度。
5. 若有条件：换线宽传感器或换压强再测一组，交叉验证。

## 7. 风险与对策

| 风险 | 表现 | 对策 |
|------|------|------|
| PI 过厚淹没石墨信号 | \(k_g\) 不敏感、残差对 \(H_{\mathrm{PI}}\) 更敏感 | 按 §1 减薄 PI；压低 \(R_c\) |
| 薄 PI 机械/绝缘失效 | 短路、皱褶、接触不均 | 工艺验证；压合均匀；Ref 自检 |
| 接触热阻过大或不可重复 | \(k_g\) 次次变；偏低 | 定压夹具；脂量标准化；先做 Ref |
| 参数强耦合（脂厚 ↔ \(k_g\)） | 多组解、cost 平坦 | 分步固定参数；减少自由参数 |
| 石墨高 \(k\) + 薄层 | 温升差被界面淹没 | 加厚石墨或换更敏结构；接受测的是「等效热阻」 |
| 各向异性 | 单 \(k\) 拟合差 | 引入 \(\psi=k_x/k_y\)；或明确只报交叉平面有效值 |
| 低频基底有限厚度 | 相位/斜率偏离半无限 | 模型用有限基底；或提高最低频 |
| 滤波未稳 | 低频点乱跳 | 增大等待倍数至 8～10 |
| 导电样品漏电 | \(V_1\) 异常、噪声大 | 检查 PI/脂绝缘；确认无金属毛刺短路 |
