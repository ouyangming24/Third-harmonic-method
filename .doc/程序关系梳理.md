# 3ω 热物性测量系统 — 程序关系梳理

> 对应仓库根目录下核心 Python 脚本。日常推荐入口：`python 3omega_gui.py`。

---

## 1. 总览：两条主线

```text
测量线：仪器驱动 → 采集 / 调平 → 主界面
反演线：正演模型 → 优化器 → 拟合适配 → 主界面 / 入口
```

| 入口 | 说明 |
|------|------|
| `python 3omega_gui.py` | **推荐**：界面与旧程序一致，拟合走信赖域反射（TRF），可切换自写 / SciPy |
| `python thermal_measurement_gui2.py` | 旧入口：欠松弛高斯-牛顿拟合 |
| `python instrument_gui.py` | 独立温阻联测 / TCR 标定（不经过主 GUI） |
| `python sensitivity_analys26.py` | 离线灵敏度脚本（功能已被主 GUI 灵敏度页覆盖） |

---

## 2. 依赖关系简图

```text
                    ┌─ 3omega_gui.py ──────────────┐
                    │  (推荐入口, 挂载 TRF 拟合)      │
                    └────────────┬─────────────────┘
                                 ▼
                 thermal_measurement_gui2.py  ←──── 也可直接作为旧入口运行
                    │
     ┌──────────────┼──────────────┬────────────────┐
     ▼              ▼              ▼                ▼
olson_model26_3  trf_fitter    calibration_gui   锁相 / 调平
     ▲              │              │          ┌────┴─────────────┐
     │              ▼              ▼          ▼                  ▼
     │         trf_optimizer  signal_calibration  Zurich / OE1300
     │                                       balance_resistor
     │                                       auto_balance
     │
```

拟合时的典型调用链：

```text
GUI 点「拟合」
  → trf_fitter（或旧版 ThermalModelFitter）
    → olson_model26_3 正演算 V₃(f)
    → trf_optimizer 迭代参数
```

## 3. 按功能分类

### 3.1 程序入口 / 主界面

| 脚本 | 作用 |
|------|------|
| **`3omega_gui.py`** | 推荐启动入口。加载主界面，把拟合器替换为 TRF；拟合设置页可切换「自写 Coleman–Li / SciPy least_squares」 |
| **`thermal_measurement_gui2.py`** | 核心大 GUI：锁相测量、数据拟合、灵敏度、穿透深度、可视化、材料库、传感器库等几乎全部界面 |

关系：`3omega_gui` 是薄壳入口；真正页面都在 `thermal_measurement_gui2`。

---

### 3.2 物理正演 + 反演核心

| 脚本 | 作用 |
|------|------|
| **`olson_model26_3.py`** | Olson 多层 3ω **正演**（\(Z\to V_3\)）；材料 / 传感器 / 多线宽联合拟合类；含 \(k_y\)/\(k_x\) 各向异性、各向同性标记、χ 积分加速等 |
| **`trf_optimizer.py`** | **纯优化器**（Coleman–Li / SciPy TRF）。只接收残差函数，不导入 GUI、不导入 Olson |
| **`trf_fitter.py`** | **适配层**：用 Olson 算残差，调用 `trf_optimizer`；`install_into_gui_module()` 可把 GUI 内拟合器换成 TRF 版 |

---

### 3.3 锁相 / 测量硬件驱动

| 脚本 | 作用 |
|------|------|
| **`苏黎世锁相适配3.py`** | Zurich 锁相驱动（扫频、读 1ω/3ω 等） |
| **`oe1300_lockin.py`** | OE1300 锁相驱动（TCP / 串口 ASCII） |
| **`balance_resistor.py`** | 平衡电阻箱串口控制（调平用可变电阻） |
| **`auto_balance.py`** | **自动调平线程**：协调锁相 + 电阻箱，把差分 1ω 调到目标 |

主界面「锁相控制」页调用以上模块；测量时可选 Zurich 或 OE1300。

---

### 3.4 信号校正（通路相位 / 基线）

| 脚本 | 作用 |
|------|------|
| **`signal_calibration.py`** | 校正算法（相位传递函数、基线扣除等） |
| **`calibration_gui.py`** | 校正用 GUI 页，嵌入主程序 |

拟合前可对 \(V_{3\omega}\) 做通路校正，减小仪器相位与基线误差。

---

### 3.5 独立小工具（弱耦合或不进主流程）

| 脚本 | 作用 | 与主程序关系 |
|------|------|----------------|
| **`instrument_gui.py`** | 温阻联测 / TCR 标定（宇电温度 + 电阻仪），Tk 独立窗口 | **独立程序**；标定得到的 \(\alpha_R\) 再填入主 GUI |
| **`sensitivity_analys26.py`** | 早期脚本式灵敏度分析（Matplotlib） | 功能上已被主 GUI「灵敏度分析」页替代，可作离线脚本 |

## 4. 按日常任务速查

| 你要做的事 | 主要改 / 用的脚本 |
|------------|-------------------|
| 打开整套测量 + 拟合软件 | `3omega_gui.py` |
| 改界面、测量流程、拟合页交互 | `thermal_measurement_gui2.py` |
| 改 3ω 物理公式、\(k_y\)/\(k_x\)、积分 | `olson_model26_3.py` |
| 改拟合算法、收敛、速度相关优化器 | `trf_optimizer.py`、`trf_fitter.py` |
| 接 Zurich / OE1300 | `苏黎世锁相适配3.py` / `oe1300_lockin.py` |
| 自动调平 | `auto_balance.py` + `balance_resistor.py` |
| 信号通路校正 | `signal_calibration.py` + `calibration_gui.py` |
| 单独做 TCR 温阻标定 | `instrument_gui.py` |
| 不进 GUI 的灵敏度脚本 | `sensitivity_analys26.py` |

## 5. 一句话记忆

- **`thermal_measurement_gui2`**：躯干（界面与业务流程）
- **`olson_model26_3` + `trf_*`**：脑子（正演与反演）
- **锁相 / 电阻 / 调平脚本**：手脚（仪器）
- **`3omega_gui`**：换了更好拟合引擎的启动器
- **`instrument_gui`、`sensitivity_analys26`**：旁边的独立工具
