# 纤维丝 3ω 模型 — 简化推导

本文是 `纤维丝模型推导.md` 的精简版：只保留**关键步骤**与**关键条件**。  
完整推导与公式细节见长文。

---

## 0. 共同物理图像

1. 交流电流 $I\sim\sin\omega t$ → 焦耳热含 **直流 + $2\omega$**  
2. 温度出现直流温升 + **$2\omega$ 波动**（热容使温升落后于功率）  
3. $\delta R=R'\,\Delta T$ → 电压出现 **$3\omega$**  
4. 锁相测 $V_{3\omega}(f)$，与热模型拟合 → $\kappa$、$C_p$（或 $\alpha$）

**共同边界（模型假设，代码不自动检查）：**

$$
T(0,t)=T(L,t)=T_0
\quad\Leftrightarrow\quad
\Delta(0)=\Delta(L)=0
$$

两端钉在热沉温度；中间悬空段升温，热沿**轴向**流向两端。

## 0.5 导电 vs 绝缘：推导并列对比（何处开始不同）

两条线**前半段相同**，从「谁在导电 / 热方程怎么写」开始分叉。

### 相同（尚未分叉）

| 步骤 | 导电与绝缘共同内容 |
|------|-------------------|
| A | 悬空段长度 $L$，两端热沉 $T=T_0$ |
| B | $I\sim\sin\omega t$ → 功率含 $2\omega$ → 温升波动 → $\delta R=R'\Delta T$ → $V_{3\omega}$ |
| C | 目标：由 $V_{3\omega}(f)$ 反推轴向 $\kappa$、$\alpha$（或 $C_p$） |

### 分叉点一览

| 环节 | 导电丝 (Lu) | 绝缘丝镀层 | **差异本质** |
|------|-------------|------------|--------------|
| **① 样品结构** | 丝**本体**导电 | 芯**不导电**，表面**镀金属** | 谁发热、谁提供 $R,R'$ |
| **② 电学参数** | $R,R'$ = 纤维 | $R,R'$ = **镀层**；$\kappa,\rho,C_p$ = **芯** | 参数归属不同 |
| **③ 热方程写法** | 时间域 PDE + 冲量响应 | 直接对 **$2\omega$ 谐波**写常微分（复振幅） | 求解路线不同 |
| **④ 空间展开** | 傅里叶正弦级数 $\sin(n\pi x/L)$，常截断 $n=1$ | **不解级数**；闭式 $\sinh(mL)$ | Lu 有 $n$、$\gamma$；绝缘有 $m$、$F$ |
| **⑤ 特征量** | $\gamma=L^2/(\pi^2\alpha)$，$2\omega\gamma$ | $m^2=i2\omega/\alpha+4h_r/(D\kappa)$ | 频段尺子不同 |
| **⑥ 辐射** | 可选；进 $g$ → $\kappa_{\mathrm{ap}},\gamma_{\mathrm{ap}}$ | 常写入 $m^2$ 的 $h_r$ 项 | 同一物理，嵌入位置不同 |
| **⑦ 最终 $V_3$** | $\propto 1/\sqrt{1+(2\omega\gamma)^2}$ + 规定相位 | $\propto R'\,F(m)$（$F$ 自带复相位） | **公式不同，勿混用** |
| **⑧ 截断/极限** | 条件 (10)(31)；$2\omega\gamma\lesssim 4$；低/高频式 (22)(23) | 薄镀层 $t\ll D$；低/高频式 (9)(10) | 适用条件列表不同 |

### 推导流程对照（读到哪一步开始不像）

```
共同：两端 T0 + 焦耳热 + R' 测温
              │
     ┌────────┴────────┐
     ▼                 ▼
  导电：本体发热        绝缘：镀层发热（芯导热）
     │                 │
     ▼                 ▼
  时间域热方程          频域 2ω 方程（含 hr）
  + 正弦级数 n          + 复波数 m
     │                 │
     ▼                 ▼
  截断 n=1 → γ         传递函数 F(m)
     │                 │
     ▼                 ▼
  式(19) 幅值+相位      V3 ∝ R' F(m)
```

**一句话**：物理图像同类（轴向一维、两端热沉、3ω）；**从“导电通道是谁”开始不同**，随后求解手段（级数 $\gamma$ vs 复 $m$）和最终公式整支分开。GUI 必须切换模型，不能共用一条正演。

### 低 / 高频衡量（两边各自的尺子）

| | 导电 | 绝缘 |
|--|------|------|
| 无量纲量 | $2\omega\gamma$ | $|mL|$（或看是否接近 LF/HF 极限式） |
| 低频（约 10 倍） | $2\omega\gamma\lesssim 0.1$ → 平台、主得 $\kappa$ | $|mL|$ 小 / 近式 (9) → 主得 $\kappa$ |
| 高频（约 10 倍） | $2\omega\gamma\gtrsim 10$ → $\propto 1/\omega$、主得 $C_p$ | 近式 (10) → 主得 $\rho C_p$ |

## 1. 导电丝（Lu 2001）

### 1.1 关键步骤

| 步骤 | 内容 |
|------|------|
| ① | 一维热方程 + 两端 $\Delta=0$ + 过去已稳态（$t\to-\infty$） |
| ② | 空间用正弦级数 $\sin(n\pi x/L)$（因两端为 0） |
| ③ | 丢掉电阻反馈非线性（条件 10）→ 各模独立衰减 |
| ④ | 只留 $n=1$ → 幅值式 (19)、相位 $\tan\varphi\approx 2\omega\gamma$ |
| ⑤ | 由 $\gamma$ 得 $C_p$；可选式 (24)、辐射表观修正 |

特征时间：

$$
\gamma=\frac{L^2}{\pi^2\alpha},\qquad
\alpha=\frac{\kappa}{\rho C_p}
$$

实用公式（rms，幅值；代码用 $|R'|$ + 按 $R'$ 符号定相位）：

$$
|V_{3\omega}|\approx
\frac{4\,I_{\mathrm{rms}}^3\,L\,R\,|R'|}{\pi^4\kappa S\sqrt{1+(2\omega\gamma)^2}}
$$

$$
\tan\varphi\approx 2\omega\gamma
$$

$$
C_p=\frac{\pi^2\gamma\kappa}{\rho L^2}
$$

### 1.2 关键条件

| 条件 | 式子 | 含义 | 不满足时 |
|------|------|------|----------|
| **(10) 线性化** | $\dfrac{I_0^2 R'L}{\pi^2\kappa S}\ll 1$（看 $n=1$） | 电阻反馈发热可忽略 | 减小电流 |
| **(31) 辐射** | $g\gamma\ll 1$ | 径向辐射可忽略 | 开辐射修正 / 缩短 $L$ |
| **单模窗口** | $2\omega\gamma\lesssim 4$ | 只留 $n=1$ 误差可接受 | 勿扫太高；或改用高频极限 |
| **端点热沉** | 接点导热好 | $\Delta(0)=\Delta(L)=0$ | 工艺保证（代码不检查） |

$g=16\varepsilon\sigma T_0^3/(\rho C_p D)$；$I_0=\sqrt{2}\,I_{\mathrm{rms}}$。

### 1.3 频段直觉

- **低频**（$2\omega\gamma\to 0$）：平台 → 主要得 **$\kappa$**  
- **高频**（$2\omega\gamma\to\infty$）：$\propto 1/\omega$ → 主要得 **$C_p$**  
- **中间扫频**：同时拟合 $\kappa$ 与 $C_p$

## 2. 绝缘丝镀层（Xing / Munro）

### 2.1 关键步骤

| 步骤 | 内容 |
|------|------|
| ① | 镀层通电加热/测温；$R,R'$ 为**镀层**；$\kappa,\rho,C_p$ 为**纤维芯** |
| ② | 轴向一维 + 两端 $T_0$ + 径向辐射 $h_r=4\varepsilon\sigma T_0^3$ |
| ③ | 复波数 $m^2=i2\omega/\alpha+4h_r/(D\kappa)$ |
| ④ | $V_3\propto R'\,F(m)$（sinh 传递函数） |
| ⑤ | 扫频拟合芯的 $\kappa$、$C_p$ |

$$
m^2=\frac{i2\omega}{\alpha}+\frac{4h_r}{D\kappa}
$$

$$
F(m)=\frac{2-2\cosh(mL)+mL\sinh(mL)}{L^2 m^3\sinh(mL)}
$$

低频 / 高频极限：

$$
V_3^{\mathrm{(amp)}}\xrightarrow{\mathrm{LF}}
\frac{I_0^3 R_0 R' L}{12\kappa\pi D^2}
\qquad
V_3^{\mathrm{(amp)}}\xrightarrow{\mathrm{HF}}
\frac{I_0^3 R_0 R'}{i\,2\omega\,\rho C_p\pi D^2 L}
$$

（代码：$I_0=\sqrt{2}I_{\mathrm{rms}}$，再 $/ \sqrt{2}$ 得 rms。）

### 2.2 关键条件

| 条件 | 含义 |
|------|------|
| **镀层很薄** $t\ll D$ | 镀层热容/轴向导热可忽略；**不需要**镀层厚度进公式 |
| **径向近似均匀** | 芯内径向温差小（细丝、不太高频） |
| **细长丝开辐射** | $h_r$ 写入 $m^2$，否则 $\kappa$ 易偏高 |
| **两端热沉** | 同导电丝，靠接点保证 |
| **$R,R'$ 标定** | 镀层需退火 + $R(T)$ |

### 2.3 与导电丝的关系

详见上文 **§0.5 并列对比**。此处只强调：加热体与公式不同，**不可**把绝缘数据套进 Lu 式 (19)。

## 3. 相位（实验注意）

- **物理**：温度落后于加热；频率越高，滞后越大（往正交靠）。  
- **同号 $R'$ 下**，当前代码里导电与绝缘相位曲线约差 **180°**（公式符号约定），**不是**两种材料物理反向。  
- **接法固定**后，测得相位正负就固定；模型符号标定一次对齐即可，不要每次改接线迁就模型。

## 4. 一页清单（做实验 / 跑 GUI）

**导电丝**

1. 填 $L,D$（或 $S$）、$R,R',I_{\mathrm{rms}}$，$\rho$  
2. 检查条件 (10)(31)、$2\omega\gamma\lesssim 4$  
3. 拟合 $\kappa$、$C_p$；细长高温可开辐射  

**绝缘丝**

1. 填镀层 $R,R'$，芯 $\kappa,\rho,C_p$，外径 $D$  
2. 细长丝开 $\varepsilon,T_0$  
3. 用绝缘模型拟合（勿与 Lu 公式混用）  

**两端 $\Delta T=0$**：焊盘/热沉导热 ≫ 纤维 $\kappa S/L$（粗判）；代码不验证。
