================================================================================
【主要功能】
================================================================================

1. 理论计算
   ├─ 设置材料参数 (Tab 1)
   ├─ 设置纤维参数 (Tab 2)  
   ├─ 设置频率范围 (Tab 3)
   └─ 点击"计算理论曲线"

2. 实验拟合
   ├─ 完成理论计算（设置初值）
   ├─ 点击"加载实验数据" (.xlsx/.csv)
   ├─ 选择拟合参数和模式
   └─ 点击"执行拟合"

3. 模拟测试
   ├─ 设置真实参数
   ├─ 点击"执行拟合" → 选择"是"生成模拟数据
   └─ 查看拟合精度

================================================================================
【参数范围】
================================================================================

材料参数:
  热导率 κ:   0.01 ~ 10,000 W/(m·K)
  密度 ρ:     100 ~ 25,000 kg/m³
  比热容 Cₚ:  50 ~ 5,000 J/(kg·K)

纤维参数:
  长度 L:     0.1 ~ 100 mm
  直径 D:     0.1 ~ 1,000 μm
  电阻 R:     0.01 ~ 10,000 Ω
  温度系数 R': -1 ~ 1 Ω/K
  RMS电流 I:  0.1 ~ 1,000 mA

频率设置:
  范围:       0.01 ~ 1,000,000 Hz
  点数:       5 ~ 200

================================================================================
【拟合模式】
================================================================================

拟合类型:
  ├─ 材料参数    → 测量 κ, Cₚ, ρ
  ├─ 纤维参数    → 校准 R, R', I
  └─ 联合拟合    → 同时优化

拟合模式:
  ├─ both (实部+虚部)  → 推荐，精度最高
  ├─ amp (幅值)        → 相位不准时
  ├─ phase (相位)      → 提取比热容
  ├─ real (实部)       → 仅用实部
  └─ imag (虚部)       → 仅用虚部

算法参数:
  最大迭代:  20 (推荐)
  收敛容差:  1e-5
  步长因子:  0.5 (稳定) / 0.7 (快速)

【有效性条件】
================================================================================

条件(10) - 功率均匀性:
  I₀²·|R'|·L / (π²·κ·S) < 0.1
  ✓ 满足 → 温度分布均匀
  ✗ 不满足 → 降低电流或缩短长度

条件(31) - 辐射损失:
  g·γ < 0.1
  ✓ 满足 → 辐射可忽略
  ✗ 不满足 → 需要真空环境

频率范围:
  2·ω_max·γ < 4 (相位 < 76°)
  ✓ 合适 → 测量精度好
  ✗ 过高 → 降低最大频率

================================================================================
【推荐设置】
================================================================================

一般测量:
  频率: 1 ~ 1000 Hz, 30点, 对数
  拟合: 材料参数, both模式
  参数: κ + Cₚ

高导热材料 (κ > 500):
  频率: 10 ~ 10000 Hz
  增加电流以提高信噪比

低导热材料 (κ < 10):
  频率: 0.1 ~ 100 Hz
  降低电流避免过热

碳纳米管:
  注意负温度系数 (R' < 0)
  边界: κ ∈ [1000, 5000]

================================================================================
【故障排除】
================================================================================

拟合不收敛:
  1. 降低步长 ζ → 0.3
  2. 增加迭代次数 → 50
  3. 只拟合单参数
  4. 检查初值是否合理

有效性不满足:
  1. 条件(10) → 降低电流
  2. 条件(31) → 增大直径或真空环境
  3. 频率过高 → 降低 f_max

程序启动失败:
  1. 运行: python 测试纤维GUI.py
  2. 查看缺少哪些依赖
  3. pip install <missing_package>

数据加载失败:
  1. 检查文件格式
  2. 确保有频率/实部/虚部列
  3. 检查数据中是否有NaN
