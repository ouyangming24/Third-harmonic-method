# 3ω方法GUI系统 - 更新日志

## 版本 v1.1.1 (2025-11-09)

### 🔧 改进优化

#### 频率范围自动筛选功能

**问题:**
- v1.1中调整频率范围后,所有实验数据点仍然显示
- 包括频率范围外的数据点,导致图像混乱
- 无法聚焦于特定频率区域进行精细分析

**解决方案:**
- ✅ 自动筛选显示频率范围内的实验数据点
- ✅ 范围外的点自动隐藏
- ✅ 状态栏显示 "实验点: X/Y (范围内/总数)"
- ✅ 图像始终聚焦于当前关注的频率区间

**技术实现:**
```python
# 使用NumPy布尔索引筛选数据
mask = (exp_freq >= freq_min) & (exp_freq <= freq_max)
exp_freq_filtered = exp_freq[mask]
exp_amp_filtered = exp_amp[mask]
exp_phase_filtered = exp_phase[mask]
```

**应用场景:**
1. **分段拟合** - 低频段拟合基底,高频段拟合薄膜
2. **噪声排除** - 排除测量质量差的频率段
3. **特征频率分析** - 聚焦于转折点附近精细拟合
4. **数据质量检查** - 检查各频段的数据分布

**文档:**
- 新增 `频率范围筛选功能说明.txt` - 详细使用指南

## 版本 v1.1 (2025-11-09)

### 🎉 新增功能

#### 📥 实验数据导入功能

**主要特性:**
- ✅ 支持导入Excel格式的实验数据 (.xlsx, .xls)
- ✅ 理论曲线与实验数据在同一图中对比显示
- ✅ 实验数据点使用不同颜色和标记显示
  - 幅值图: 绿色圆点
  - 相位图: 紫色圆点
- ✅ 动态参数调整时理论曲线自动更新,实验数据保持固定
- ✅ 智能列名识别,支持多种列名格式

**界面变化:**
- 新增 `[📥 导入实验数据]` 按钮 (绿色醒目按钮)
- 新增 `[🗑️ 清除实验数据]` 按钮
- 新增实验数据文件名显示标签
- 修改 `[📊 导出数据]` → `[📊 导出理论数据]` (更明确)

**数据格式要求:**
```
必须包含列:
- 频率 (Hz)
- V3_幅值 (V)
- V3_相位 (度)

支持的备选列名:
- Frequency (Hz), frequency, freq
- V3_Magnitude (V), magnitude, amp
- V3_Phase (deg), phase
```

**使用流程:**
```
1. [📥 导入实验数据] → 选择Excel文件
2. 系统自动识别列名并加载数据
3. 实验数据点叠加显示在理论曲线上
4. 调整参数 → 观察理论与实验的拟合程度
5. [🗑️ 清除实验数据] → 移除实验数据(可选)
```

**核心代码:**
- `import_experimental_data()` - 导入功能
- `clear_experimental_data()` - 清除功能
- `calculate_and_plot()` - 更新为支持实验数据叠加绘制
