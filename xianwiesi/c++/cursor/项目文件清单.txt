========================================
快速开始指南
========================================

1️⃣ 安装依赖
   pip install -r requirements_gui.txt

2️⃣ 检查环境
   python 测试GUI.py

3️⃣ 启动程序
   Windows: 双击 "启动GUI.bat"
   或手动:   python gui_3omega.py

4️⃣ 加载示例
   程序内点击 📂 加载配置 → 选择示例配置文件

========================================
主要功能特性
========================================

✨ 实时动态更新
   - 修改参数自动重新计算
   - 300ms延迟机制避免频繁计算

🎛️ 完整参数控制
   - 传感器参数: b, L, R, dR/dT, V_rms等
   - 材料参数: k_y, ρ, c, H, Rc, ψ

📚 内置材料库
   - 10+种常用材料预设
   - 快速选择和应用

🏗️ 多层结构支持
   - 任意层数添加/删除
   - 基底自动处理为半无限厚

📊 双图显示
   - 上图: V3幅值 vs 频率
   - 下图: V3相位 vs 频率

💾 数据管理
   - 保存/加载配置(JSON)
   - 导出计算结果(Excel)

========================================
技术规格
========================================

编程语言:   Python 3.8+
GUI框架:    PyQt5
绘图库:     Matplotlib
科学计算:   NumPy, SciPy
数据处理:   Pandas

理论基础:   Olson et al. (2005) 多层结构3ω方法
计算方法:   汉克尔变换 + 递归热阻抗
更新机制:   延迟触发 (300ms)
