### 2. 理论模型模块 (`olson_model26.py`)

#### 2.1 核心计算函数

**函数调用链:**
```
calculate_analytical_Z()
    └─> [for each frequency]
        └─> integrate.quad()
            └─> integrand()
                └─> _calculate_transform_impedance()
                    └─> [递归计算多层]
```

**关键算法:**

1. **传递阻抗计算** `_calculate_transform_impedance()`
   ```python
   # 基底层 (n=0)
   φ₁ = √(ψχ² + i·4πfb²/α₁)
   z₁ = -b/(k₁·φ₁)
   
   # 递归层 (n≥1)
   φₙ = √(ψχ² + i·4πfb²/αₙ)
   tanh_term = tanh(φₙHₙ/b)
   zₙ = (b/kₙφₙ) · [(kₙφₙz̃ₙ₋₁·tanh - tanh) / (1 - kₙφₙz̃ₙ₋₁·tanh)]
   z̃ₙ = zₙ - Rcₙ
   ```

2. **汉克尔变换** `calculate_analytical_Z()`
   ```python
   Z̃(f) = (2/π) ∫₀^{4π} sinc²(χ)·z(χ,f) dχ
   ```

3. **坐标转换** `convert_Z_to_V3()`
   ```python
   # 修正加热器热质量 (Eq.3反演)
   Ẑ = 1/(1/Z* - i·4πf·Hₑ·ρCₑ)
   
   # 转换为电压 (Eq.2反演)
   V3 = Ẑ / [-(4R²bL)/(V_rms³·dR/dT)]
   ```

#### 2.2 参数拟合类 `ThermalModelFitter`

**拟合算法:** 高斯-牛顿法

**数学原理:**
```
最小化残差: min Σ|V3_exp - V3_model(p)|²

迭代公式:
D = [p·∂V3/∂p]        # 灵敏度矩阵
A = D·Dᵀ              # Hessian近似
B = D·(V3_exp - V3_model)
求解: A·c = B
更新: p_new = (1 + ζ·c)·p_old
```

**三种拟合模式:**
- **material**: 拟合材料热物性 (k_y, Rc, ρ, c等)
- **sensor**: 拟合传感器参数 (R, dR/dT, V_rms等)
- **combined**: 同时拟合材料和传感器参数

**五种拟合目标:**
- **both**: 实部+虚部
- **real**: 仅实部
- **imag**: 仅虚部
- **amp**: 幅值
- **phase**: 相位

## 🔄 数据流向

### 正向计算流程 (参数 → 图像)

```
1. 用户输入参数
   ↓
2. 触发 paramChanged 信号
   ↓
3. schedule_update() 启动300ms定时器
   ↓
4. 定时器到期 → calculate_and_plot()
   ↓
5. 收集参数
   • get_sensor_params()
   • get_layers()
   • update_frequency_range()
   ↓
6. 计算理论曲线
   • calculate_analytical_Z(freqs, b, layers)
     [汉克尔积分 + 递归热阻抗]
   • convert_Z_to_V3(Z, freqs, b, sensor_params)
     [坐标转换]
   ↓
7. 提取幅值和相位
   • V3_amp = |V3| * 1000  (转mV)
   • V3_phase = unwrap(angle(V3)) * 180/π
   ↓
8. 更新图像
   • 清空画布
   • 绘制新曲线
   • 刷新显示
   ↓
9. 更新状态栏
```

### 反向拟合流程 (实验数据 → 参数)

```
1. 加载实验V3数据
   ↓
2. 设置初始猜测参数
   ↓
3. ThermalModelFitter.fit()
   ↓
4. 迭代循环 (最多max_iter次)
   ├─> 计算当前模型预测 V3_model
   ├─> 计算灵敏度矩阵 D = p·∂V3/∂p
   ├─> 构建正规方程 A·c = B
   ├─> 求解修正系数 c
   ├─> 更新参数 p_new = (1+ζc)p_old
   ├─> 应用边界约束
   └─> 检查收敛性 ε < tol
   ↓
5. 输出拟合结果
```

## ⚙️ 关键技术决策

### 1. 延迟更新机制

**问题:** 用户输入过程中频繁触发计算,导致界面卡顿

**解决方案:**
```python
self.update_timer = QTimer()
self.update_timer.setSingleShot(True)  # 单次触发
self.update_timer.timeout.connect(self.calculate_and_plot)

def schedule_update(self):
    self.update_timer.start(300)  # 300ms延迟
```

**优点:**
- 避免输入过程中的中间状态计算
- 提升用户体验
- 降低CPU占用

### 2. 信号槽机制

**问题:** 多个组件间的通信和同步

**解决方案:** PyQt信号槽
```python
# 发射信号
self.paramChanged.emit()

# 连接槽函数
widget.paramChanged.connect(self.schedule_update)
```

**优点:**
- 松耦合设计
- 事件驱动
- 易于扩展

### 3. 向量化计算

**问题:** 多频率点的循环计算效率低

**解决方案:**
```python
# NumPy向量化
V3_amp = np.abs(V3_analytical)
V3_phase = np.unwrap(np.angle(V3_analytical))
```

**优点:**
- 充分利用NumPy C底层
- 计算速度提升10-100倍
- 代码简洁

### 4. 参数验证

**问题:** 非法输入导致计算崩溃

**解决方案:**
```python
# 输入验证器
self.k_y_input.setValidator(QDoubleValidator(0.001, 10000, 6))

# 异常捕获
try:
    layers = self.get_layers()
except ValueError as e:
    self.status_label.setText(f"错误: {str(e)}")
    return
```

**优点:**
- 提前拦截非法输入
- 友好的错误提示
- 提高程序鲁棒性

## 🔍 性能优化

### 1. 计算复杂度

**频域积分:**
- 复杂度: O(N_freq × N_quad)
- N_freq = 100 (频率点)
- N_quad ≈ 50 (积分求值次数)
- 单次计算: ~5000次函数评估

**优化策略:**
- 自适应积分 (scipy.integrate.quad)
- 合理的积分上限 (0 到 4π)
- 向量化不可并行的部分

### 2. 内存管理

**大数组处理:**
```python
# 预分配
Z_analytical = np.zeros(len(freqs), dtype=complex)

# 就地操作
V3_amp *= 1e3  # 而不是创建新数组
```

### 3. GUI响应性

**策略:**
- 计算前调用 `QApplication.processEvents()`
- 状态标签实时更新
- 防止长时间阻塞UI线程
