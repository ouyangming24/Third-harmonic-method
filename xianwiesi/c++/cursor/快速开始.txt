┌──────────────────────────────────────────────────────────────────┐
│  🚀 三步快速启动                                                  │
└──────────────────────────────────────────────────────────────────┘

  第1步: 安装依赖库
  ──────────────────────────────────────
  命令行执行:
  
    pip install -r requirements_gui.txt
  
  安装内容: NumPy, SciPy, Matplotlib, PyQt5, Pandas


  第2步: 检查环境 (可选但推荐)
  ──────────────────────────────────────
  命令行执行:
  
    python 测试GUI.py
  
  检查内容: 依赖库完整性, 模型计算, GUI框架


  第3步: 启动GUI程序
  ──────────────────────────────────────
  Windows用户:
  
    双击运行 → 启动GUI.bat
  
  或手动执行:
  
    python gui_3omega.py


┌──────────────────────────────────────────────────────────────────┐
│  📚 加载示例配置                                                  │
└──────────────────────────────────────────────────────────────────┘

  程序启动后:
  
  1. 点击左下角 [📂 加载配置] 按钮
  
  2. 选择示例配置文件:
     • 示例配置_SiO2薄膜.json    (Si/SiO2双层结构)
     • 示例配置_三层结构.json    (Glass/Mica/CNO三层)
  
  3. 观察自动生成的幅值和相位曲线

┌──────────────────────────────────────────────────────────────────┐
│  ❓ 常见问题快速解答                                              │
└──────────────────────────────────────────────────────────────────┘

  Q: 程序无法启动?
  A: 运行 python 测试GUI.py 检查环境
  
  Q: 改参数后没反应?
  A: 等待300ms自动更新, 或检查输入值是否合法
  
  Q: 计算结果是NaN?
  A: 检查k_y, ρ, c是否为正值, 使用材料库预设值
  
  Q: 如何理解特征频率?
  A: f_c ≈ α/(2πb²), 低于看基底, 高于看薄膜
  
  更多问题? 查看 GUI使用说明.md 完整FAQ章节

┌──────────────────────────────────────────────────────────────────┐
│  💡 使用技巧                                                      │
└──────────────────────────────────────────────────────────────────┘

  技巧1: 从材料库开始
    先选择预设材料 → 再微调参数 (避免非物理值)

  技巧4: 观察特征频率

    系统改变某参数 → 保存多组配置 → 对比曲线
