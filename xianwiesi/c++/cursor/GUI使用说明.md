# 3ω 方法热物性测量 GUI 系统使用说明

## 📋 功能概述

这是一个用于3ω方法热物性测量的交互式图形界面系统,支持:

- ✅ **实时动态调整参数** - 传感器参数和材料热物性参数可随时修改
- ✅ **自动更新图像** - 参数改变后自动重新计算并更新幅值/相位曲线
- ✅ **多层结构支持** - 可添加任意层数的材料层
- ✅ **材料库管理** - 内置常用材料参数,支持快速选择
- ✅ **配置保存/加载** - 支持保存和加载实验配置
- ✅ **数据导出** - 可导出计算结果到Excel文件

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements_gui.txt
```

### 2. 启动程序

**Windows 用户:**
```bash
双击运行 "启动GUI.bat"
```

**或手动启动:**
```bash
python gui_3omega.py
```

## 🎯 界面布局

### 左侧参数面板(分为3个标签页)

#### 📡 标签页1: 传感器参数

**几何参数:**
- `b` - 加热丝半宽 (μm)
- `L` - 加热丝长度 (mm)

**电学参数:**
- `R` - 电阻 (Ω)
- `dR/dT` - 电阻温度系数 (Ω/K)
- `V_rms` - RMS电压 (V)

**加热器参数:**
- `H_e` - 加热器厚度 (nm)
- `ρC_e` - 体积热容 (J/m³·K)

#### 🔬 标签页2: 材料层

每层包含以下参数:

- **材料选择** - 从材料库快速选择预设材料
- `k_y` - 热导率 (W/m·K)
- `ρ` - 密度 (kg/m³)
- `c` - 比热容 (J/kg·K)
- `H` - 厚度 (μm) - 基底层自动设为无穷大
- `Rc` - 界面热阻 (K·m²/W)
- `ψ` - 各向异性因子

**操作按钮:**
- `➕ 添加新层` - 在顶部添加新的材料层
- `删除此层` - 移除选定的材料层(基底层除外)

**层结构说明:**
- 第0层: 基底层(半无限厚,不能删除)
- 第1层及以上: 薄膜层(从下往上堆叠)

#### 📊 标签页3: 频率范围

- **最小频率** - 扫频起始频率 (Hz)
- **最大频率** - 扫频结束频率 (Hz)  
- **数据点数** - 频率点的数量

### 右侧绘图区域

**双子图显示:**
- **上图** - V3电压幅值随频率变化曲线
- **下图** - V3电压相位随频率变化曲线

**坐标轴:**
- X轴: 对数频率刻度
- Y轴(上): 幅值 (mV)
- Y轴(下): 相位 (度)

**状态栏:**
- 显示计算状态、层数、基底热扩散率等信息

## 📝 使用流程

### 基本工作流程

1. **设置传感器参数**
   - 切换到"传感器参数"标签页
   - 输入实验使用的传感器几何和电学参数

2. **配置材料层**
   - 切换到"材料层"标签页
   - 从下拉菜单选择基底材料(第0层)
   - 点击"➕ 添加新层"添加薄膜层
   - 可手动修改任何参数值

3. **调整频率范围**(可选)
   - 切换到"频率范围"标签页
   - 设置适合实验的频率扫描范围

4. **观察曲线变化**
   - 任何参数修改后,系统会自动(延迟300ms)重新计算
   - 图像实时更新显示新的幅值和相位曲线

### 高级功能

#### 💾 保存配置

1. 点击左下方 `💾 保存配置` 按钮
2. 选择保存位置和文件名
3. 配置保存为 JSON 格式

**用途:** 保存实验配置供以后使用

#### 📂 加载配置

1. 点击左下方 `📂 加载配置` 按钮
2. 选择之前保存的 JSON 配置文件
3. 所有参数自动恢复

#### 📊 导出数据

1. 点击左下方 `📊 导出数据` 按钮
2. 选择保存位置(默认: 3omega_data.xlsx)
3. 导出包含以下列的Excel文件:
   - 频率 (Hz)
   - V3_实部 (V)
   - V3_虚部 (V)
   - V3_幅值 (V)
   - V3_相位 (度)

## 🔍 实际应用示例

### 示例1: Si/SiO2双层结构

**目标:** 测量SiO2薄膜的热导率

**步骤:**
1. 传感器参数:
   - b = 200 μm
   - L = 5 mm
   - R = 6.74 Ω
   - dR/dT = 0.014391 Ω/K

2. 材料层配置:
   - 第0层(基底): 选择 "Si"
   - 添加第1层(薄膜): 选择 "SiO2", 设置厚度 H = 1.5 μm

3. 观察曲线:
   - 低频段: 信号受基底Si影响
   - 高频段: 信号受SiO2薄膜影响
   - 特征频率处出现转折

### 示例2: 多层异质结构

**目标:** 分析 Glass/Mica/CNO 三层结构

**步骤:**
1. 第0层: Glass (基底)
2. 第1层: 自定义 Mica 参数
3. 第2层: 自定义 CNO 参数

4. 调整各层:
   - 界面热阻 Rc
   - 厚度 H
   - 观察对相位曲线的影响

### 示例3: 界面热阻敏感性分析

**目标:** 研究界面热阻对测量结果的影响

**步骤:**
1. 设置基本的双层结构
2. 逐步改变第1层的 Rc 值: 1e-8 → 1e-7 → 1e-6 → 1e-5
3. 观察幅值和相位曲线的变化规律
4. 保存不同配置进行对比

## ⚙️ 技术细节

### 计算原理

基于 **Olson et al. (2005)** 论文的理论模型:

1. **热扩散率计算:**
   ```
   α = k_y / (ρ × c)
   ```

2. **递归计算多层热阻抗**
   - 从基底层开始
   - 逐层向上累积
   - 考虑界面热阻和有限厚度效应

3. **频域积分**
   - 汉克尔变换
   - 积分范围 [0, 4π]

4. **坐标转换**
   - Z* → V3 电压信号

### 性能优化

- **延迟更新机制:** 参数修改后300ms才触发计算,避免输入过程中频繁计算
- **异常处理:** 完善的错误捕获和提示机制
- **参数验证:** 输入值范围检查,防止非物理参数

## ❗ 常见问题

### Q1: 修改参数后图像不更新?

**A:** 检查:
- 输入的数值是否合法(如负数、零等)
- 状态栏是否显示错误信息
- 尝试点击其他输入框触发更新

### Q2: 计算结果出现NaN或Inf?

**A:** 可能原因:
- 参数值超出物理范围
- 热扩散率过小(检查 k_y, ρ, c 的值)
- 频率范围设置不合理

**解决方法:**
- 使用材料库的预设值作为起点
- 逐步调整参数,观察曲线变化

### Q3: 如何理解热扩散率?

**A:** 
- 热扩散率 α = k/(ρc) 表示热量传播的快慢
- 典型值范围: 1e-7 ~ 1e-4 m²/s
- Si: ~8.6e-5 m²/s
- SiO2: ~7.9e-7 m²/s

### Q4: 相位曲线出现跳变?

**A:** 
- 这是相位缠绕现象
- 程序使用 `np.unwrap()` 自动处理
- 如仍有问题,尝试增加频率点数

### Q5: 导出数据失败?

**A:** 确保:
- 已安装 pandas 和 openpyxl 库
- 目标文件未被其他程序占用
- 有足够的磁盘空间

## 🔧 自定义扩展

### 添加新材料到材料库

编辑 `gui_3omega.py` 中的 `MaterialsLibrary` 类:

```python
self.materials = {
    # ... 现有材料 ...
    '新材料名': {
        'k_y': 热导率值,
        'rho': 密度值,
        'cap': 比热容值,
        'H': 默认厚度值,
        'psi': 1.0,
        'Rc': 界面热阻值
    }
}
```

### 修改延迟更新时间

在 `MainWindow.__init__()` 中修改:

```python
self.update_timer.start(300)  # 改为你想要的毫秒数
```
