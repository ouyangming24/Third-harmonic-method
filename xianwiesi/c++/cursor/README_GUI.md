# 3ω方法热物性测量 - 交互式GUI系统

## 🎯 项目简介

这是一个基于Olson理论模型的3ω方法热物性测量交互式GUI系统,支持实时动态调整参数并自动更新幅值/相位曲线图。

![GUI界面](https://img.shields.io/badge/Interface-PyQt5-green)
![Python](https://img.shields.io/badge/Python-3.8+-blue)
![License](https://img.shields.io/badge/License-MIT-yellow)

## ✨ 核心特性

### 🔥 实时动态更新
- 修改任何参数后,系统自动重新计算
- 幅值和相位曲线实时更新
- 300ms延迟机制,避免输入过程中频繁计算

### 🎛️ 完整参数控制

**传感器参数:**
- 几何尺寸: 半宽b, 长度L
- 电学参数: 电阻R, 温度系数dR/dT, RMS电压
- 加热器参数: 厚度H_e, 体积热容ρC_e

**材料热物性参数:**
- 热导率 k_y (W/m·K)
- 密度 ρ (kg/m³)
- 比热容 c (J/kg·K)
- 厚度 H (μm)
- 界面热阻 Rc (K·m²/W)
- 各向异性因子 ψ

### 📚 内置材料库

预设10+种常用材料:
- 半导体: Si, SiO2
- 金属: Al, Cu
- 陶瓷: Al2O3, Diamond, Glass
- 聚合物: PI (聚酰亚胺)
- 导热介质: Ag_Grease, Air
- 自定义材料

### 🏗️ 多层结构支持
- 任意层数堆叠
- 每层独立参数设置
- 动态添加/删除材料层
- 基底层自动处理为半无限厚

### 💾 数据管理
- **保存配置**: JSON格式保存所有参数
- **加载配置**: 快速恢复之前的实验设置
- **导出数据**: Excel格式导出计算结果(频率、实部、虚部、幅值、相位)

## 📖 使用教程

### 基础操作

#### 1️⃣ 设置传感器参数

```
传感器参数标签页 → 输入实验参数
```

**典型值参考:**
- b = 200 μm (中等尺寸传感器)
- L = 5 mm
- R = 6.74 Ω
- dR/dT = 0.014 Ω/K
- V_rms = 0.4 V

#### 2️⃣ 配置材料层

```
材料层标签页 → 选择材料 / 输入参数
```

**操作步骤:**
1. 第0层(基底): 从下拉菜单选择材料
2. 点击"➕ 添加新层"增加薄膜层
3. 每层可独立设置材料和参数
4. 点击"删除此层"移除不需要的层

#### 3️⃣ 调整频率范围

```
频率范围标签页 → 设置扫频区间
```

**推荐设置:**
- 最小频率: 0.0001 Hz (低频段看基底影响)
- 最大频率: 1000 Hz (高频段看薄膜影响)
- 数据点数: 100 (平衡精度和速度)

#### 4️⃣ 观察曲线

修改任何参数后:
- 系统自动计算 (300ms延迟)
- 上图显示幅值曲线
- 下图显示相位曲线
- 状态栏显示计算信息

## 🔧 技术细节

### 理论基础

基于 **Olson et al. (2005)** 的多层结构3ω方法理论:

**关键公式:**

1. **热扩散率:**
   ```
   α = k_y / (ρ × c)
   ```

2. **特征波数:**
   ```
   φ = √(ψχ² + i·4πfb²/α)
   ```

3. **递归热阻抗:**
   ```
   z_n = (b/k_n·φ_n) · [(k_n·φ_n·z_{n-1}·tanh - tanh) / (1 - k_n·φ_n·z_{n-1}·tanh)]
   ```

4. **汉克尔变换:**
   ```
   Z̃ = (2/π) ∫₀^{4π} sinc²(χ) · z(χ) dχ
   ```

### 计算流程

```
参数输入 → 层结构定义 → 频域计算 → 汉克尔积分 → Z*计算 → V3转换 → 图像绘制
```

### 性能优化

- **延迟更新:** 防止输入时频繁计算
- **向量化计算:** 充分利用NumPy加速
- **异步绘图:** 不阻塞UI响应
- **参数验证:** 提前拦截非法输入

## ❓ 常见问题

### Q: 程序无法启动?
**A:** 
1. 运行 `python 测试GUI.py` 检查环境
2. 确保Python版本 >= 3.8
3. 重新安装依赖: `pip install -r requirements_gui.txt --upgrade`

### Q: 修改参数后没反应?
**A:** 
- 等待300ms自动更新
- 检查输入值是否合法(状态栏显示错误)
- 尝试点击其他输入框触发更新

### Q: 计算结果异常(NaN/Inf)?
**A:** 
- 检查热导率、密度、比热容是否为正值
- 热扩散率过小可能导致数值不稳定
- 使用材料库预设值作为起点

### Q: 如何理解特征频率?
**A:** 
特征频率 f_c ≈ α/(2πb²)
- 低于f_c: 热波穿透深度 > 薄膜厚度,看到基底
- 高于f_c: 热波穿透深度 < 薄膜厚度,看到薄膜

### Q: 相位曲线有跳变?
**A:** 
- 已使用 `np.unwrap()` 自动处理相位缠绕
- 如仍有问题,增加频率点数(如200点)
