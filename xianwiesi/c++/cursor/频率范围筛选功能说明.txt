│  💡 使用示例                                                      │
└──────────────────────────────────────────────────────────────────┘

  场景1: 聚焦高频区域
  ────────────────────────────────────
  
    1. 导入实验数据 (0.0001 Hz ~ 1000 Hz, 共100点)
    
    2. 初始频率范围: 0.0001 ~ 1000 Hz
       → 显示全部100个实验数据点
    
    3. 调整频率范围: 10 ~ 1000 Hz
       → 只显示高频段的实验数据点 (例如50点)
       → 状态栏: "实验点: 50/100 (范围内/总数)"
    
    4. 图像聚焦于高频区域
       → 细节更清晰
       → 拟合更精确


  场景2: 聚焦低频区域
  ────────────────────────────────────
  
    1. 导入实验数据 (0.0001 Hz ~ 1000 Hz, 共100点)
    
    2. 调整频率范围: 0.0001 ~ 1 Hz
       → 只显示低频段的实验数据点 (例如30点)
       → 状态栏: "实验点: 30/100 (范围内/总数)"
    
    3. 观察基底材料的影响
       → 低频段对基底热导率敏感
       → 可以精确拟合基底参数


  场景3: 特征频率附近精细分析
  ────────────────────────────────────
  
    1. 计算特征频率: f_c ≈ α/(2πb²)
       例如: f_c ≈ 10 Hz
    
    2. 调整频率范围: 1 ~ 100 Hz
       → 聚焦于特征频率附近
       → 只显示该区间的实验点
    
    3. 精确拟合转折区域
       → 对热导率最敏感的区域
       → 拟合精度最高

┌──────────────────────────────────────────────────────────────────┐
│  🔧 技术实现                                                      │
└──────────────────────────────────────────────────────────────────┘

  核心算法:
  ────────────────────────────────────
  
  1. 获取当前频率范围
     freq_min = self.freqs.min()
     freq_max = self.freqs.max()
  
  2. 创建布尔掩码筛选数据
     mask = (exp_freq >= freq_min) & (exp_freq <= freq_max)
  
  3. 应用掩码提取范围内的点
     exp_freq_filtered = exp_freq[mask]
     exp_amp_filtered = exp_amp[mask]
     exp_phase_filtered = exp_phase[mask]
  
  4. 绘制筛选后的数据
     if len(exp_freq_filtered) > 0:
         plot(exp_freq_filtered, exp_amp_filtered)
  
  
  优点:
  ────────────────────────────────────
  
  ✓ 高效: NumPy布尔索引,毫秒级处理
  ✓ 准确: 严格的区间判断 (>=, <=)
  ✓ 鲁棒: 空集合保护 (len > 0 检查)
  ✓ 灵活: 支持任意频率范围


┌──────────────────────────────────────────────────────────────────┐
│  💡 应用技巧                                                      │
└──────────────────────────────────────────────────────────────────┘

  技巧1: 分段拟合策略
  ────────────────────────────────────
  
    问题: 全频段数据拟合困难
    
    解决:
    1. 低频段拟合基底参数
       → 设置频率范围: 0.0001 ~ 1 Hz
       → 调整 Si 的 k_y
    
    2. 高频段拟合薄膜参数
       → 设置频率范围: 10 ~ 1000 Hz
       → 调整 SiO2 的 k_y
    
    3. 全频段验证
       → 设置频率范围: 0.0001 ~ 1000 Hz
       → 检查整体拟合质量


  技巧2: 噪声区域排除
  ────────────────────────────────────
  
    问题: 某些频率段测量噪声大
    
    解决:
    1. 观察实验数据,识别噪声段
    2. 调整频率范围,排除噪声段
    3. 在高质量数据区间拟合参数


  技巧3: 特征频率精确定位
  ────────────────────────────────────
  
    目标: 找到准确的特征频率
    
    方法:
    1. 粗略估算: f_c ≈ α/(2πb²)
    2. 设置范围: 0.1*f_c ~ 10*f_c
    3. 观察理论与实验的转折点
    4. 微调参数使转折点对齐


  技巧4: 数据质量检查
  ────────────────────────────────────
  
    检查步骤:
    1. 设置频率范围为实验数据的全范围
    2. 观察各频段的点分布密度
    3. 识别数据缺失或异常的区域
    4. 针对性调整测量或数据处理


┌──────────────────────────────────────────────────────────────────┐
│  ⚠️ 注意事项                                                     │
└──────────────────────────────────────────────────────────────────┘

  1. 频率范围不要过窄
     ────────────────────────────────────
     • 至少保留10个以上实验数据点
     • 过少的点无法有效约束拟合
     • 建议: 范围内点数 ≥ 待拟合参数数 × 5
  
  
  2. 注意边界点
     ────────────────────────────────────
     • 边界判断使用 >= 和 <=
     • 边界上的点会被包含
     • 对数坐标下,边界精确对齐
  
  
  3. 空集合处理
     ────────────────────────────────────
     • 如果范围内无数据点,不会绘制
     • 不会报错,只显示理论曲线
     • 状态栏显示: "实验点: 0/100"
  
  
  4. 实验数据保持不变
     ────────────────────────────────────
     • 筛选只影响显示,不修改原始数据
     • 调整回原频率范围,数据完整恢复
     • 可以随意调整频率范围探索

  完整的数据分析流程:
  
  第1步: 导入数据,全局观察
  ──────────────────────────────────────────
    • 频率范围: 实验数据的全范围
    • 目的: 了解整体趋势
    • 操作: [📥 导入实验数据]
  
  
  第2步: 识别关键频率区域
  ──────────────────────────────────────────
    • 观察: 转折点,平台区,噪声区
    • 估算: 特征频率 f_c
    • 记录: 有价值的频率范围
  
  
  第3步: 聚焦低频,拟合基底
  ──────────────────────────────────────────
    • 频率范围: f_min ~ 0.1*f_c
    • 调整: 基底材料 k_y
    • 目标: 低频段拟合良好
  
  
  第4步: 聚焦高频,拟合薄膜
  ──────────────────────────────────────────
    • 频率范围: 10*f_c ~ f_max
    • 调整: 薄膜材料 k_y, Rc
    • 目标: 高频段拟合良好
  
  
  第5步: 全频段验证
  ──────────────────────────────────────────
    • 频率范围: 恢复全范围
    • 检查: 整体拟合质量
    • 评估: 残差分布
  
  
  第6步: 保存结果
  ──────────────────────────────────────────
    • [💾 保存配置] → 保存拟合参数
    • [📊 导出理论数据] → 导出拟合曲线
    • 记录: 拟合参数和不确定度
