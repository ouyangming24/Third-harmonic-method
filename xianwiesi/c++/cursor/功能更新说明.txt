┌──────────────────────────────────────────────────────────────────┐
│  📊 数据格式要求                                                  │
└──────────────────────────────────────────────────────────────────┘

  Excel 文件必须包含以下列:
  
    ┌─────────────┬──────────────┬──────┐
    │   列名      │     说明     │ 单位 │
    ├─────────────┼──────────────┼──────┤
    │ 频率 (Hz)   │  测量频率    │  Hz  │
    │ V3_幅值 (V) │  3ω电压幅值  │  V   │
    │ V3_相位 (度)│  3ω电压相位  │  度  │
    └─────────────┴──────────────┴──────┘
  
  注意: 
  • 幅值单位是 V (不是 mV)
  • 相位单位是 度 (不是弧度)
  • 与 run_fit_savetxt26.py 导出格式完全一致

┌──────────────────────────────────────────────────────────────────┐
│  🎛️ 使用流程                                                     │
└──────────────────────────────────────────────────────────────────┘

  完整的参数拟合工作流:
  
  1️⃣ 导入实验数据
     [📥 导入实验数据] → 选择文件 → 看到数据点
  
  2️⃣ 设置传感器参数 (已知值)
     传感器参数标签页 → 输入 b, L, R, dR/dT 等
  
  3️⃣ 配置材料层结构
     材料层标签页 → 选择基底 → 添加薄膜层
  
  4️⃣ 调整热物性参数
     修改 k_y (热导率) → 观察理论曲线变化
     ↓
     理论曲线自动更新
     ↓
     对比实验数据点
     ↓
     继续调整直到最佳拟合
  
  5️⃣ 微调界面热阻
     调整 Rc → 优化拟合质量
  
  6️⃣ 保存拟合结果
     [💾 保存配置] → 保存最佳参数

┌──────────────────────────────────────────────────────────────────┐
│  💡 实用技巧                                                      │
└──────────────────────────────────────────────────────────────────┘

  技巧1: 从材料库开始
  ────────────────────────────────────
    先选择接近的预设材料 → 再微调参数
    避免从完全错误的初始值开始
  
  
  技巧2: 观察特征频率
  ────────────────────────────────────
    幅值/相位转折点 = 热扩散深度 ≈ 层厚
    
    • 低频: 基底主导
    • 高频: 薄膜主导
    • 转折频率: f_c ≈ α/(2πb²)
  
  
  技巧3: 参数调整顺序
  ────────────────────────────────────
    1. 先调主要参数 (k_y 热导率)
    2. 再调次要参数 (Rc 界面热阻)
    3. 最后微调其他参数 (ρ, c)
    
    每次只改一个参数,观察影响!
  
  
  技巧4: 多组数据对比
  ────────────────────────────────────
    • 测量多组数据
    • 依次导入对比
    • 检查重复性
    • 评估不确定度
  
  
  技巧5: 保存拟合历史
  ────────────────────────────────────
    每次拟合后保存配置:
    • "拟合_v1.json"
    • "拟合_v2.json"
    • "拟合_最终.json"
    
    便于回溯和对比


┌──────────────────────────────────────────────────────────────────┐
│  ⚠️ 常见问题                                                     │
└──────────────────────────────────────────────────────────────────┘

  Q1: 导入失败 - "缺少列: 频率 (Hz)"
  ────────────────────────────────────
  A: 检查 Excel 列名是否正确
     
     正确示例:
     频率 (Hz) | V3_幅值 (V) | V3_相位 (度)
     
     如果列名不同,系统会尝试自动识别:
     • Frequency (Hz) → 频率 (Hz)
     • V3_magnitude → V3_幅值 (V)
  
  
  Q2: 导入后看不到数据点
  ────────────────────────────────────
  A: 检查以下几点:
     1. 数据点是否在当前频率范围内?
        → 调整频率范围标签页的最小/最大频率
     
     2. 幅值单位是否正确?
        → 应该是 V (伏特), 不是 mV (毫伏)
        → 如果显示异常,可能单位错误
     
     3. 放大图像查看
        → 可能数据点被理论曲线遮挡
  
  
  Q3: 理论曲线和实验数据差别很大
  ────────────────────────────────────
  A: 正常! 这就是需要拟合的原因
     
     解决方法:
     1. 检查传感器参数是否正确
     2. 检查层结构是否正确
     3. 调整材料热导率 k_y
     4. 调整界面热阻 Rc
     5. 耐心调整直到拟合良好
  
  
  Q4: 如何判断拟合好坏?
  ────────────────────────────────────
  A: 观察以下指标:
     
     ✓ 幅值曲线: 理论线穿过实验点附近
     ✓ 相位曲线: 转折点位置吻合
     ✓ 整体趋势: 斜率和曲率一致
     
     注意: 完美拟合很难,追求总体趋势一致
