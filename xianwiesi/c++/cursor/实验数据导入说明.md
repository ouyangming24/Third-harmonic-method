# 实验数据导入功能使用说明

## 📥 功能概述

GUI系统现已支持**导入实验数据**并在同一图中与理论曲线进行对比显示。这对于参数拟合和模型验证非常有用。

---

## 📊 支持的数据格式

### 标准格式 (与 `run_fit_savetxt26.py` 相同)

Excel文件必须包含以下列:

| 列名 | 说明 | 单位 | 必需 |
|------|------|------|------|
| `频率 (Hz)` | 测量频率 | Hz | ✓ |
| `V3_幅值 (V)` | 3ω电压幅值 | V | ✓ |
| `V3_相位 (度)` | 3ω电压相位 | 度 | ✓ |
| `V3_实部 (V)` | 实部 (可选) | V | - |
| `V3_虚部 (V)` | 虚部 (可选) | V | - |

### 备选列名 (自动识别)

系统可以自动识别以下备选列名:

**频率:**
- `Frequency (Hz)`
- `frequency`
- `freq`
- `Freq`

**幅值:**
- `V3_Magnitude (V)`
- `V3_magnitude`
- `magnitude`
- `amp`

**相位:**
- `V3_Phase (deg)`
- `V3_phase`
- `phase`
- `Phase`

## 🚀 使用步骤

### 1️⃣ 准备实验数据文件

确保您的Excel文件格式正确:

```
频率 (Hz)  | V3_幅值 (V) | V3_相位 (度)
-----------|-------------|-------------
0.0001     | 0.00523     | -45.2
0.001      | 0.00487     | -48.6
0.01       | 0.00412     | -52.1
...        | ...         | ...
```

### 2️⃣ 启动GUI并导入数据

**方法A: 直接导入**
```
1. 启动 GUI: python gui_3omega.py
2. 点击左下角 [📥 导入实验数据] 按钮
3. 选择实验数据Excel文件
4. 确认导入成功
```

**方法B: 使用示例数据**
```
1. 运行: python 生成示例实验数据.py
2. 生成 "示例实验数据_SiO2.xlsx"
3. 在GUI中导入此文件
```

### 3️⃣ 查看对比效果

导入成功后:
- ✅ **蓝色实线** = 理论曲线 (根据当前参数计算)
- ✅ **绿色圆点** = 实验数据点 (幅值图)
- ✅ **紫色圆点** = 实验数据点 (相位图)
- ✅ 状态栏显示实验数据点数
- ✅ 左下角显示已加载的文件名

### 4️⃣ 动态调整参数

**核心功能:**
- 修改任何传感器或材料参数
- 理论曲线自动更新
- 实验数据点保持不变
- 实时观察理论与实验的拟合程度

**典型工作流程:**
```
导入实验数据
    ↓
调整材料热导率 k_y
    ↓
观察理论曲线变化
    ↓
继续调整其他参数 (Rc, ρ, c等)
    ↓
找到最佳拟合参数
    ↓
保存配置
```

### 5️⃣ 清除实验数据

不需要实验数据时:
```
点击 [🗑️ 清除实验数据] 按钮
```
- 实验数据点从图中移除
- 只显示理论曲线
- 可随时重新导入

## 💡 应用场景

### 场景1: 参数拟合

**目标:** 从实验数据反推材料热导率

**步骤:**
1. 导入实验数据
2. 设置已知的传感器参数和层结构
3. 调整未知的热导率 `k_y`
4. 观察理论曲线与实验点的吻合度
5. 微调 `Rc` (界面热阻)
6. 重复调整直到达到最佳拟合

**提示:**
- 从材料库选择接近的材料作为初始猜测
- 先调整主要参数 (k_y), 再调整次要参数 (Rc)
- 关注特征频率区域的拟合质量

### 场景2: 模型验证

**目标:** 验证理论模型的准确性

**步骤:**
1. 使用已知材料制备样品
2. 测量实验数据并导入
3. 设置材料的标准参数值
4. 比较理论与实验曲线
5. 评估模型的预测能力

### 场景3: 不确定度分析

**目标:** 研究参数不确定性的影响

**步骤:**
1. 导入实验数据(含测量噪声)
2. 在参数边界范围内调整
3. 观察哪些参数对拟合影响最大
4. 确定关键的敏感参数

## 🔧 高级功能

### 1. 生成模拟实验数据

使用提供的脚本生成带噪声的模拟数据:

```bash
python 生成示例实验数据.py
```

**可定制参数:**
- 噪声水平
- 频率范围
- 数据点数
- 材料结构

**用途:**
- 测试GUI功能
- 算法验证
- 教学演示

### 2. 列名自动识别

如果您的Excel文件列名不完全匹配,系统会尝试:
1. 查找精确匹配
2. 查找备选名称
3. 模糊匹配(部分包含)

**示例:**
```
"Frequency (Hz)" → 识别为 "频率 (Hz)"
"V3_mag"         → 识别为 "V3_幅值 (V)"
"phase_deg"      → 识别为 "V3_相位 (度)"
```

### 3. 数据点数不匹配处理

**情况:** 实验数据和理论计算的频率点数不同

**解决方案:**
- 实验数据和理论曲线各自独立绘制
- 使用不同标记区分 (线条 vs 点)
- 对数坐标自动对齐

**不需要:**
- ❌ 插值
- ❌ 频率点对齐
- ❌ 数据重采样

## ⚠️ 注意事项

### 数据质量检查

导入前检查:
- ✓ 频率值为正数
- ✓ 幅值为正数
- ✓ 相位范围合理 (-180° ~ 180°)
- ✓ 无缺失值 (NaN)
- ✓ 频率单调递增

### 单位一致性

确保单位正确:
| 参数 | Excel列 | 单位 |
|------|---------|------|
| 频率 | 频率 (Hz) | Hz |
| 幅值 | V3_幅值 (V) | V (不是mV!) |
| 相位 | V3_相位 (度) | 度 (不是弧度!) |

### 文件格式

支持的Excel格式:
- ✓ `.xlsx` (推荐)
- ✓ `.xls` (旧格式)

不支持:
- ❌ `.csv` (可在Excel中另存为 .xlsx)
- ❌ `.txt`

## 🐛 故障排除

### 问题1: "缺少列: 频率 (Hz)"

**原因:** 列名不匹配

**解决:**
1. 打开Excel文件
2. 检查列标题
3. 重命名为标准列名:
   - `频率 (Hz)`
   - `V3_幅值 (V)`
   - `V3_相位 (度)`

### 问题2: 导入后看不到数据点

**检查:**
1. 数据点是否在当前频率范围内?
2. 幅值单位是否正确? (应为V,不是mV)
3. 相位是否有异常值?

**解决:**
- 调整频率范围使其包含实验数据范围
- 在Excel中检查数值是否合理

### 问题3: 图像显示异常

**可能原因:**
- 数据范围差异过大
- 相位有跳变

**解决:**
- 使用对数坐标(自动)
- 检查相位连续性

## 📝 完整示例

### 示例: SiO2薄膜热导率测量

**1. 实验数据文件 (测量值.xlsx):**
```
频率 (Hz) | V3_幅值 (V) | V3_相位 (度)
----------|-------------|-------------
0.001     | 0.00523     | -45.2
0.01      | 0.00487     | -48.6
0.1       | 0.00412     | -52.1
1.0       | 0.00351     | -55.8
10.0      | 0.00298     | -59.2
100.0     | 0.00267     | -61.5
```

**2. GUI操作:**
```
a. [📥 导入实验数据] → 选择 "测量值.xlsx"
b. 传感器参数标签页 → 输入已知参数
   - b = 200 μm
   - L = 5 mm
   - R = 6.74 Ω
   - dR/dT = 0.014391 Ω/K
   
c. 材料层标签页 → 配置层结构
   - 第0层: Si (基底)
   - 第1层: SiO2, 厚度 H = 1.5 μm
   
d. 调整 SiO2 的 k_y
   - 初始值: 1.4 W/m·K
   - 观察拟合情况
   - 调整到最佳值
   
e. 微调界面热阻 Rc
   - 范围: 1e-8 ~ 1e-4 K·m²/W
   
f. [💾 保存配置] → "SiO2_拟合结果.json"
```

**3. 结果分析:**
- 拟合得到: k_y = 1.12 W/m·K
- Rc = 8.5e-5 K·m²/W
- 理论与实验吻合良好
