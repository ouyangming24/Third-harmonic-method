# 纤维丝3ω方法热物性测量系统 - GUI使用说明

## 🚀 快速开始

### 安装

1. **确保已安装 Python 3.7+**

2. **安装依赖包**：
   ```bash
   pip install -r requirements_fiber_gui.txt
   ```

3. **启动GUI**：
   - Windows: 双击 `启动纤维GUI.bat`
   - 或命令行: `python gui_fiber_3omega.py`

## 🎛️ 功能模块详解

### 1. 材料参数设置

**预设材料库：**
- **platinum** (铂丝) - 标准参考材料
  - κ = 71.6 W/(m·K)
  - ρ = 21450 kg/m³
  - Cₚ = 133 J/(kg·K)

- **carbon_nanotube** (碳纳米管束)
  - κ = 3000 W/(m·K) (轴向)
  - ρ = 1300 kg/m³
  - Cₚ = 700 J/(kg·K)

- **copper** (铜丝)
  - κ = 401 W/(m·K)
  - ρ = 8960 kg/m³
  - Cₚ = 385 J/(kg·K)

- **tungsten** (钨丝)
- **nichrome** (镍铬合金)
- **Custom** (自定义)

**参数范围：**
- 热导率 κ: 0.01 ~ 10,000 W/(m·K)
- 密度 ρ: 100 ~ 25,000 kg/m³
- 比热容 Cₚ: 50 ~ 5,000 J/(kg·K)

### 2. 纤维参数设置

**预设配置：**
- **platinum_wire_20um** - 20μm铂丝
  - L = 8 mm
  - D = 20 μm
  - R = 5 Ω
  - R' = 0.01 Ω/K

- **carbon_nanotube_bundle** - 碳纳米管束
  - L = 1 mm
  - D = 10 μm
  - R = 50 Ω
  - R' = -0.05 Ω/K (负温度系数)

- **thin_wire_1um** - 超细丝
- **Custom** - 自定义

**参数说明：**
- **长度 L** (mm): 电压触点间距离
- **直径 D** (μm): 纤维直径
- **横截面积 S** (μm²): 自动计算 = π(D/2)²
- **电阻 R** (Ω): 常温电阻
- **温度系数 R'** (Ω/K): dR/dT，可正可负
- **RMS电流 I** (mA): 交流电流有效值

### 3. 频率范围设置

**参数：**
- **起始频率**: 0.01 ~ 1,000,000 Hz
- **终止频率**: 0.01 ~ 1,000,000 Hz
- **数据点数**: 5 ~ 200 点
- **频率间隔**: 对数/线性

**推荐设置：**
- 一般测量: 1 ~ 1000 Hz, 30点, 对数间隔
- 高频测量: 100 ~ 10000 Hz
- 低频测量: 0.1 ~ 100 Hz

### 4. 有效性检查

实时显示模型适用性：

**条件(10) - 功率均匀性**
```
I₀²·|R'|·L / (π²κS) < 0.1
```
✓ 满足: 温度分布均匀，模型有效
✗ 不满足: 温度梯度过大，结果可能不准

**条件(31) - 辐射损失**
```
g·γ < 0.1
其中 g = 16·ε·σ·T₀³/(ρ·Cₚ·D)
```
✓ 满足: 辐射损失可忽略
✗ 不满足: 需要考虑辐射修正

**频率范围 (2ωγ_max)**
```
2ω_max·γ < 4  (即 φ < 76°)
```
✓ 合适: 相位范围合理
✗ 过高: 频率过高，信噪比下降

### 5. 拟合控制

#### 拟合类型

**A. 材料参数拟合**
- 用途：测量未知材料的热物性
- 固定：纤维参数（已知）
- 拟合：κ, Cₚ, ρ

**B. 纤维参数拟合**
- 用途：传感器校准
- 固定：材料属性（标准样品）
- 拟合：R, R', I

**C. 联合拟合**
- 用途：同时优化材料和传感器参数
- 拟合：可选的材料和纤维参数

#### 拟合模式

| 模式 | 数学目标 | 适用场景 |
|------|---------|---------|
| **both (实部+虚部)** | min Σ[\|Re(ΔV)\|² + \|Im(ΔV)\|²] | 推荐，信息最全 |
| **amp (幅值)** | min Σ[\|V_exp\| - \|V_fit\|\]² | 相位不准确时 |
| **phase (相位)** | min Σ[φ_exp - φ_fit]² | 提取比热容 |
| **real (实部)** | min Σ[Re(ΔV)]² | 仅用实部 |
| **imag (虚部)** | min Σ[Im(ΔV)]² | 仅用虚部 |

#### 算法参数

- **最大迭代**: 5~100（推荐20）
- **收敛容差**: 通常 1e-5
- **步长因子 ζ**: 0.1~1.0（推荐0.5）
  - 小值：收敛慢但稳定
  - 大值：收敛快但可能振荡

- **模拟噪声**: 0~50%（仅生成模拟数据时使用）

## 🎯 使用流程

### 流程 1: 理论曲线计算

1. 在"材料参数"标签页选择材料（如 platinum）
2. 在"纤维参数"标签页选择配置（如 platinum_wire_20um）
3. 在"频率设置"标签页设置频率范围（如 1~1000 Hz, 30点）
4. 点击 **"计算理论曲线"** 按钮
5. 查看绘图区域和有效性检查结果

### 流程 2: 实验数据拟合

1. 完成理论曲线计算（设置初值）
2. 点击 **"加载实验数据"** 
   - 支持格式：Excel (.xlsx, .xls), CSV (.csv)
   - 数据列要求：
     - Frequency / freq
     - V3_Real / real
     - V3_Imag / imag

3. 在"拟合控制"区域设置：
   - 选择"材料参数"拟合
   - 勾选要拟合的参数（如 κ 和 Cₚ）
   - 选择拟合模式（推荐 both）

4. 点击 **"执行拟合"**

5. 查看结果：
   - 绘图区：实验数据 vs 拟合曲线
   - 结果显示：拟合参数、导出量
   - 控制台：详细迭代过程

6. 导出结果：
   - JSON：完整参数和结果
   - CSV：频率-电压数据
   - 图像：PNG/PDF/SVG

### 流程 3: 模拟数据测试

1. 设置理论参数
2. 点击 **"执行拟合"**
3. 在弹出对话框选择"是"生成模拟数据
4. 自动添加噪声并执行拟合
5. 对比初值和拟合值，验证算法

## 🎓 使用案例

### 案例 1: 碳纳米管热导率测量

**步骤：**
1. 材料参数：选择 "carbon_nanotube"
2. 纤维参数：选择 "carbon_nanotube_bundle"
3. 频率：1 ~ 100 Hz, 30点, 对数
4. 点击"计算理论曲线"
5. 加载实验数据（或生成模拟数据）
6. 拟合控制：
   - 类型：材料参数
   - 勾选：κ 和 Cₚ
   - 模式：both
7. 执行拟合
8. 查看结果：拟合的轴向热导率

**预期结果：**
- κ_axial ≈ 3000 W/(m·K)
- Cₚ ≈ 700 J/(kg·K)

### 案例 2: 铂丝传感器校准

**步骤：**
1. 材料参数：选择 "platinum" (已知标准)
2. 纤维参数：输入待校准的传感器参数
3. 加载实验数据
4. 拟合控制：
   - 类型：纤维参数
   - 勾选：R 和 R'
   - 模式：both
5. 执行拟合
6. 获得校准后的 R 和 R'

### 案例 3: 未知材料测试

**步骤：**
1. 材料参数：选择 "Custom"，输入粗略估计值
2. 纤维参数：选择已知配置
3. 设置合适的频率范围（建议宽频）
4. 加载实验数据
5. 拟合控制：
   - 类型：材料参数
   - 勾选：κ, Cₚ, ρ（全部）
   - 模式：both
   - 增加迭代次数到 30-50
6. 执行拟合
7. 检查收敛性和有效性

## 🔧 故障排除

### 问题 1: 拟合不收敛

**原因：**
- 初值偏离太远
- 数据噪声过大
- 参数不可辨识

**解决：**
1. 调整初值更接近真值
2. 降低步长因子 ζ → 0.3
3. 增加最大迭代次数
4. 检查有效性条件
5. 尝试只拟合单个参数

### 问题 2: 有效性条件不满足

**条件(10)不满足：**
- 降低电流 I
- 使用温度系数更小的材料
- 减小纤维长度

**条件(31)不满足：**
- 降低测试温度
- 使用直径更大的纤维
- 在真空或惰性气体环境测试

**频率范围过高：**
- 降低最大频率
- 缩短纤维长度 L

### 问题 3: 程序启动失败

**检查依赖：**
```bash
pip list | findstr PyQt5
pip list | findstr numpy
pip list | findstr matplotlib
```

**重新安装：**
```bash
pip uninstall PyQt5
pip install PyQt5
```

## 💡 最佳实践

### 测量建议

1. **频率选择**：
   - 覆盖至少 2 个数量级
   - 包含低频点（提取 κ）
   - 包含高频点（提取 Cₚ）

2. **初值设置**：
   - 使用文献值或经验估计
   - 初值偏差 < 50% 为佳

3. **拟合策略**：
   - 先单参数拟合（如只拟合 κ）
   - 再多参数拟合
   - 使用 both 模式获得最高精度

4. **结果验证**：
   - 检查有效性条件
   - 对比不同拟合模式的结果
   - 绘制残差图
