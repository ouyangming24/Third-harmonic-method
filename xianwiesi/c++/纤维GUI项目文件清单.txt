【功能模块清单】
================================================================================

GUI组件:
  ├─ FiberMaterialsLibrary         - 材料库 (5种材料)
  ├─ FiberConfigLibrary            - 配置库 (3种配置)
  ├─ MaterialParamsWidget          - 材料参数输入
  ├─ FiberParamsWidget             - 纤维参数输入
  ├─ FrequencyRangeWidget          - 频率设置
  ├─ ValidityCheckWidget           - 有效性检查显示
  ├─ PlotCanvas                    - 4图绘图区
  ├─ FittingControlWidget          - 拟合控制
  ├─ ResultsDisplayWidget          - 结果显示
  └─ FiberThermal3OmegaGUI         - 主窗口

核心功能:
  ├─ calculate_fiber_V3omega()     - 3ω电压计算
  ├─ FiberThermalFitter            - 参数拟合
  ├─ check_validity_conditions()   - 有效性检查
  ├─ create_fiber_material_library() - 材料库
  └─ create_typical_fiber_params()   - 配置库

拟合支持:
  ├─ 材料参数拟合 (κ, Cₚ, ρ)
  ├─ 纤维参数拟合 (R, R', I)
  └─ 联合拟合 (material + fiber)

拟合模式:
  ├─ both  (实部+虚部)
  ├─ amp   (幅值)
  ├─ phase (相位)
  ├─ real  (实部)
  └─ imag  (虚部)

数据格式:
  输入:  Excel (.xlsx/.xls), CSV
  输出:  JSON, CSV, PNG/PDF/SVG

【使用流程】
================================================================================

快速上手 (5分钟):
  1. 启动GUI
  2. 材料参数 → 选择 "platinum"
  3. 纤维参数 → 选择 "platinum_wire_20um"
  4. 点击"计算理论曲线"
  5. 点击"执行拟合" → 生成模拟数据
  6. 查看拟合结果

完整测量流程:
  1. 设置初始参数（材料+纤维）
  2. 设置频率范围
  3. 计算理论曲线（验证参数）
  4. 加载实验数据
  5. 配置拟合（类型/模式/参数）
  6. 执行拟合
  7. 查看结果和有效性
  8. 导出数据和图像

【特别说明】
================================================================================

1. 图表标签全英文
   所有坐标轴、标题、图例均使用英文
   符合国际学术论文发表标准

2. 测量方向
   本模型测量 轴向热导率 (Axial Thermal Conductivity)
   热流方向沿纤维长度方向

3. 与薄膜模型区别
   薄膜3ω (olson_model26.py): 测量横向热导率 (Cross-plane)
   纤维3ω (fiber_model.py):   测量轴向热导率 (Axial)

4. 各向异性材料
   对于碳纳米管等各向异性材料:
   κ_axial (沿管轴) >> κ_radial (径向)
   本模型测得 κ_axial
