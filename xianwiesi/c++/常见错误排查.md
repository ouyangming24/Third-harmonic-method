# GUI常见错误排查指南

## 错误 1: x and y must have same first dimension

### 错误信息
```
ValueError: x and y must have same first dimension, but have shapes (99,) and (30,)
```

### 原因分析

这个错误通常发生在以下情况：

1. **频率设置与实验数据不匹配**
   - GUI中设置的频率点数 = 30
   - 加载的实验数据频率点数 = 99
   - 绘图时使用了不同的频率数组

2. **理论曲线计算时使用了错误的频率**
   - 先计算了理论曲线（30点）
   - 后加载实验数据（99点）
   - 尝试在同一图上绘制不同长度的数据

### 解决方案

#### 方案 1: 自动修复（已实现）

最新版本的代码已经添加了自动检测和修复：

```python
# 在 plot_V3omega 函数中
if len(freqs) != len(V3_omega):
    print(f"警告: 频率数组长度不匹配")
    min_len = min(len(freqs), len(V3_omega))
    freqs = freqs[:min_len]
    V3_omega = V3_omega[:min_len]
```

**操作**：重新运行程序即可

#### 方案 2: 重新计算理论曲线

**步骤**：
1. 加载实验数据后，会自动使用实验数据的频率重新计算理论曲线
2. 确保 `self.current_freqs` 在加载数据时被正确更新
3. 所有后续计算都使用 `self.current_freqs`

#### 方案 3: 手动清除和重新计算

**操作流程**：
1. 先点击"加载实验数据"
2. 然后点击"计算理论曲线"（这会用实验的频率重新计算）
3. 最后点击"执行拟合"

### 预防措施

**建议工作流程**：

**方法 A（推荐）- 先加载数据**
```
1. 加载实验数据（确定频率数组）
   ↓
2. 自动用实验频率计算理论曲线
   ↓
3. 执行拟合
```

**方法 B - 先设置理论**
```
1. 设置频率范围（在GUI中）
   ↓
2. 计算理论曲线
   ↓
3. 确保加载的实验数据频率范围与设置一致
```

## 错误 2: 无法识别数据列

### 错误信息
```
无法识别数据列，请确保包含:
- 频率列 (Frequency)
- 实部列 (V3_Real)
- 虚部列 (V3_Imag)
```

### 原因
数据文件的列名不符合识别规则

### 解决方案

#### 支持的列名格式

**频率列**（包含以下关键词之一）：
- `freq`
- `Frequency`
- `frequency`
- `FREQ`

**实部列**（同时包含以下两个关键词）：
- `real` 和 `v3`
- 例如：`V3_Real`, `v3_real`, `V3Real`

**虚部列**（同时包含以下两个关键词）：
- `imag` 和 `v3`
- 例如：`V3_Imag`, `v3_imag`, `V3Imag`

#### 修改数据文件

**标准格式**：
```csv
Frequency,V3_Real,V3_Imag
1.0,2.15e-4,-1.2e-5
2.0,1.85e-4,-2.1e-5
...
```

**也支持**：
```csv
freq,v3_real,v3_imag
1.0,2.15e-4,-1.2e-5
...
```

## 错误 3: 拟合不收敛

### 错误信息
```
警告: 已达到最大迭代次数但未收敛。
```

### 原因
1. 初值偏离太远
2. 数据噪声过大
3. 参数不可辨识
4. 步长因子不合适

### 解决方案

#### 调整算法参数

**降低步长因子**（更稳定）：
```
步长因子 ζ: 0.5 → 0.3
```

**增加迭代次数**：
```
最大迭代: 20 → 50
```

#### 调整拟合策略

**单参数拟合**（更稳定）：
```
只勾选 κ (先拟合热导率)
收敛后再勾选 Cₚ
```

**改变拟合模式**：
```
both → amp (如果相位有问题)
both → phase (如果幅值有问题)
```

#### 改善初值

**使用文献值**：
- 查找类似材料的热导率
- 使用合理的估计值

**分步拟合**：
1. 先用 amp 模式拟合 κ
2. 再用 phase 模式拟合 Cₚ
3. 最后用 both 模式精细优化

## 错误 4: 有效性条件不满足

### 警告信息（橙色边框）
```
条件(10) - 功率均匀性: 2.5e-01 [✗ 不满足]
```

### 原因和解决

#### 条件(10)不满足

**问题**：
```
I₀²·|R'|·L / (π²·κ·S) > 0.1
```

**解决方案**：
1. **降低电流 I**：
   - 当前：10 mA
   - 调整为：5 mA

2. **使用低温度系数材料**：
   - 当前：R' = 0.01 Ω/K
   - 选择：R' = 0.001 Ω/K 的材料

3. **缩短纤维长度 L**：
   - 当前：8 mm
   - 调整为：4 mm

#### 条件(31)不满足

**问题**：
```
g·γ > 0.1  （辐射损失过大）
```

**解决方案**：
1. **增大纤维直径**：
   - 当前：20 μm
   - 调整为：50 μm

2. **降低测试温度**

3. **在真空或惰性气体环境中测试**

#### 频率范围过高

**问题**：
```
2·ω_max·γ > 4  （相位 > 76°）
```

**解决方案**：
1. **降低最大频率**：
   - 当前：1000 Hz
   - 调整为：100 Hz

2. **缩短纤维长度**（降低γ）

## 错误 6: 计算结果为NaN或Inf

### 可能原因

1. **参数设置不合理**
   - κ = 0 或负值
   - ρ = 0 或负值
   - Cₚ = 0 或负值

2. **频率范围问题**
   - 频率为0
   - 频率为负值

3. **数值溢出**
   - 参数过大
   - 电流过大

### 解决方案

**检查参数合理性**：
```
κ ∈ (0.01, 10000)
ρ ∈ (100, 25000)
Cₚ ∈ (50, 5000)
I ∈ (0.1, 1000) mA
```

**重置为默认值**：
- 材料：选择 "platinum"
- 纤维：选择 "platinum_wire_20um"
- 频率：1 ~ 1000 Hz

## 错误 7: 拟合结果不合理

### 现象
拟合的参数明显偏离预期值

### 可能原因

1. **数据质量差**
   - 噪声过大（> 10%）
   - 数据点太少（< 10）
   - 频率范围太窄

2. **初值不合适**
   - 初值偏离真值 > 5倍

3. **参数不可辨识**
   - 同时拟合过多参数
   - 频率范围不合适

### 解决方案

**改善数据质量**：
- 增加测量次数并平均
- 扩大频率范围
- 增加数据点数

**优化初值**：
- 使用文献值
- 先做粗略估计

**分步拟合**：
1. 先只拟合 κ（用 amp 模式）
2. 固定 κ，拟合 Cₚ（用 phase 模式）
3. 同时拟合 κ 和 Cₚ（用 both 模式）

**检查频率范围**：
- 低频段（<10 Hz）：对 κ 敏感
- 高频段（>100 Hz）：对 Cₚ 敏感
- 需要覆盖两个区域

## 常见问题FAQ

### Q1: 为什么有时候拟合很慢？

**A**: 
- 数据点多（>50）
- 迭代次数多（>30）
- 拟合参数多（>2）

**建议**：
- 减少数据点（筛选或降采样）
- 降低最大迭代次数
- 先单参数拟合

### Q2: 如何知道拟合结果是否可靠？

**A**: 检查以下指标
1. ✓ 收敛（显示"收敛"而非"未收敛"）
2. ✓ 有效性条件全部满足（绿色边框）
3. ✓ 拟合曲线与实验数据吻合
4. ✓ 参数在合理范围内
5. ✓ 不同拟合模式结果一致

### Q3: 生成的模拟数据总是相同？

**A**: 
使用了固定随机种子（seed=42）以确保可重复性

**如需不同噪声**：
修改 `gui_fiber_3omega.py` 第1046行：
```python
np.random.seed(42)  # 删除此行或改为 np.random.seed()
```

### Q4: 如何批量处理多个文件？

**A**: 
GUI适合单次测量，批量处理建议使用命令行：
```bash
python fit_experimental_data.py config.json
```

### Q5: 能否测量温度依赖的热导率？

**A**: 
当前版本假设常数热导率。

**扩展方向**：
- 在不同温度下多次测量
- 外部拟合 κ(T) 关系
