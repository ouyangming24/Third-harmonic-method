# 纤维丝3ω方法热物性测量系统 - GUI版本

## 📋 项目概述

基于 Lu 等人（2001）的理论模型，提供纤维丝/悬空线热物性测量的可视化界面。

**核心功能：**
- ✅ 实时3ω电压计算和可视化
- ✅ 材料参数拟合（κ, Cₚ, ρ）
- ✅ 传感器参数拟合（R, R', I）
- ✅ 联合拟合（材料+传感器）
- ✅ 模型有效性实时检查
- ✅ 多种拟合模式（both/amp/phase/real/imag）
- ✅ 配置保存/加载
- ✅ 数据导入/导出（Excel/CSV/JSON）
- ✅ 高质量图像导出（PNG/PDF/SVG）

## 🔬 核心功能详解

### 1. 理论曲线计算

**输入：**
- 材料属性（κ, ρ, Cₚ）
- 纤维参数（L, D, R, R', I）
- 频率数组

**输出：**
- V₃ω 复数电压数组
- 热扩散率 α
- 热时间常数 γ
- 4个图表显示

**数学模型：**
```
V₃ω(ω) = [4·I³·L·R·|R'|] / [π⁴·κ·S·√(1+(2ωγ)²)] · exp(i·φ)

其中：
α = κ/(ρ·Cₚ)
γ = L²/(π²·α)
φ = arctan(2ωγ)
```

### 2. 材料参数拟合

**应用场景：**
测量未知材料的热导率和比热容

**拟合参数选择：**
- ☑ κ (热导率) - 推荐
- ☑ Cₚ (比热容) - 推荐
- ☐ ρ (密度) - 可选（通常已知）

**算法：**
- 迭代最小二乘法
- 灵敏度矩阵法
- 自动边界约束

**返回：**
- 拟合的 κ, Cₚ, ρ
- 计算的 α, γ
- 收敛信息

### 3. 传感器参数拟合

**应用场景：**
使用标准样品校准传感器

**拟合参数选择：**
- ☑ R (电阻) - 推荐
- ☑ R' (温度系数) - 推荐
- ☐ I (电流) - 可选

**典型用途：**
- 新传感器校准
- 温度系数测定
- 电流校准

### 4. 联合拟合

**应用场景：**
材料和传感器参数都有不确定度

**灵活组合：**
- 材料参数: κ
- 传感器参数: R, I
- 同时优化所有参数

**注意事项：**
- 参数过多可能导致不收敛
- 建议先单独拟合再联合优化

### 5. 模型有效性检查

**实时监测3个条件：**

**条件(10) - 功率均匀性**
```
ξ₁₀ = I₀²·|R'|·L / (π²·κ·S) < 0.1
```
- ✓ 满足：温度分布均匀
- ✗ 不满足：需要降低电流或使用低R'材料

**条件(31) - 辐射损失**
```
ξ₃₁ = g·γ < 0.1
其中 g = 16·ε·σ·T₀³/(ρ·Cₚ·D)
```
- ✓ 满足：辐射可忽略
- ✗ 不满足：需要真空环境或更粗纤维

**频率范围**
```
2·ω_max·γ < 4
```
- ✓ 合适：相位 < 76°
- ✗ 过高：降低最大频率

## 🎯 最佳实践

### 数据采集建议

1. **频率覆盖范围**
   - 至少2个数量级（如 1~100 Hz）
   - 包含低频点（提取热导率）
   - 包含高频点（提取比热容）

2. **数据点数**
   - 最少: 10 点
   - 推荐: 20-30 点
   - 过多: > 50 点（计算变慢）

3. **电流选择**
   - 保证信噪比（V₃ω > 1 μV）
   - 满足条件(10)（功率均匀性）
   - 避免过热损坏样品

### 拟合参数建议

1. **初值设置**
   - 使用文献值
   - 或粗略估计（误差 < 2倍）

2. **参数选择**
   - 单参数拟合更稳定
   - 双参数（κ, Cₚ）需要宽频数据
   - 三参数慎用

3. **模式选择**
   - 数据质量好 → both
   - 相位不准 → amp
   - 提取Cₚ → phase

4. **算法参数**
   - max_iter: 20（足够）
   - tolerance: 1e-5（标准）
   - zeta: 0.5（稳定）

## 📚 理论背景

### 测量原理

纤维丝3ω方法测量 **轴向热导率 κ_axial**：

```
电流方向 = 热流方向 = 轴向
     ↓
  ═══════  纤维丝
     ↑
测得 κ_axial
```

**与薄膜方法的区别：**
- 薄膜3ω: 测量横向（cross-plane）热导率
- 纤维3ω: 测量轴向（axial）热导率

### 适用材料

**理想样品：**
- 纤维、线材、纳米管
- 长度 > 直径 × 100
- 可通电（或镀金属层）

**测量范围：**
- κ: 0.1 ~ 5000 W/(m·K)
- Cₚ: 100 ~ 5000 J/(kg·K)
- 温度: 室温附近（可扩展）
