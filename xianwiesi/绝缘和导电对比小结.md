# 绝缘丝 vs 导电丝：对比小结

配套细读：`纤维丝两模型并列推导.md`。  
本文只收「核心方程每一项含义 + 常见误解」。

---

## 0. 先纠正常见误解

不完全是「绝缘比导电多一个辐射、热容写法不一样」。

| 误解 | 实际情况 |
|------|----------|
| 差别主要是辐射 | 辐射**不是**分水岭；导电也可用 \(g\) 修正，绝缘用 \(h_r\) 写入 \(m^2\) |
| 两边热容物理不同 | **同一物理**：\(\rho C_p\partial T/\partial t\) ↔ 频域 \(i2\omega\,\rho C_p\tilde{\Delta}\) |
| 绝缘没有两端 \(\Delta=0\) | **两边都有**两端热沉；\(\sinh/\cosh\) 正是该边界下的解 |
| 导电永远不算辐射 | 常可忽略（\(g\gamma\ll 1\)）；细长/高温仍要算 |

**真正差别**：谁发热/测温（本体 vs 镀层）、\(R,R'\) 与 \(\kappa,C_p\) 归属、求解路线（正弦级数 \(\gamma\) vs 复波数 \(m\)/\(F(m)\)）、最终 \(V_3\) 公式不同——**不能混用**。

两边骨架一样：

> **轴向导热 + 热容（±辐射）= 焦耳热**

## 1. 两个核心方程：每一项是什么

两个式子都是能量守恒：左边/中间是**怎么带走或存住热**，右边是**焦耳热从哪来**。

### 1.1 式① 导电丝（时间域，Lu）

$$
\rho C_p\frac{\partial T}{\partial t}
-\kappa\frac{\partial^2 T}{\partial x^2}
=\frac{I_0^2\sin^2\omega t}{LS}\bigl[R+R'(T-T_0)\bigr]
$$

| 块 | 含义 |
|----|------|
| $\rho C_p\,\partial T/\partial t$ | **蓄热**：体积热容 × 温度随时间变化 |
| $-\kappa\,\partial^2 T/\partial x^2$ | **轴向导热**；两端热沉靠这项把中间热带走 |
| 右端整体 | **单位体积焦耳发热功率** |
| $I_0^2\sin^2\omega t$ | 交流电流平方 → 功率含**直流 + $2\omega$** |
| $/(LS)$ | 总功率摊到体积 $L\times S$ |
| $R$ | $T_0$ 下电阻 → 主发热 |
| $R'(T-T_0)$ | 电阻随温升的**反馈发热**；后面用条件 (10) 线性化丢掉 |

一句话：时间域热容 + 轴向导热 = 交流焦耳热（含 $R'$ 反馈）。

### 1.2 式② 绝缘丝（$2\omega$ 复振幅）

假定交流温升：

$$
\Delta(x,t)=\tilde{\Delta}(x)\,e^{i2\omega t}
$$

则

$$
\kappa\frac{d^2\tilde{\Delta}}{dx^2}
-\Bigl(i2\omega\,\rho C_p+\frac{4h_r}{D}\Bigr)\tilde{\Delta}
=-q'''_{\,2\omega}
$$

| 块 | 含义 |
|----|------|
| $\kappa\,d^2\tilde{\Delta}/dx^2$ | **轴向导热**（对 $2\omega$ 复振幅）；两端 $\tilde{\Delta}=0$ 靠这项体现 |
| $i2\omega\,\rho C_p\,\tilde{\Delta}$ | **热容的频域形式**（见 §2）；$i$ 表示温升落后于加热 |
| $(4h_r/D)\,\tilde{\Delta}$ | **侧表面辐射散热**（见 §3）；$h_r=4\varepsilon\sigma T_0^3$ |
| $-q'''_{2\omega}$ | **$2\omega$ 体积发热分量**（见 §4） |

整理为 $\tilde{\Delta}''-m^2\tilde{\Delta}=\ldots$：

$$
m^2=\underbrace{\frac{i2\omega}{\alpha}}_{\text{扩散/热容}}
+\underbrace{\frac{4h_r}{D\kappa}}_{\text{辐射}}
$$

一句话：轴向导热应对「热容惯性 + 辐射损失」，右端是 $2\omega$ 焦耳热源。

### 1.3 对照表

| 物理 | 导电式① | 绝缘式② |
|------|---------|---------|
| 蓄热/热容 | $\rho C_p\,\partial T/\partial t$ | $i2\omega\,\rho C_p\,\tilde{\Delta}$ |
| 轴向导热 | $-\kappa\,\partial^2 T/\partial x^2$ | $\kappa\,d^2\tilde{\Delta}/dx^2$ |
| 发热 | 全时域 $R+R'\Delta$ 功率 | 只取 $2\omega$ 分量 $q'''_{2\omega}$ |
| 辐射 | 主式常不写；用 $g$ 表观修正 | 显式 $(4h_r/D)\tilde{\Delta}$ |

## 2. 绝缘热容项为什么是 $i2\omega\,\rho C_p\tilde{\Delta}$？

绝缘模型不直接解时间域 PDE，只盯 $2\omega$ 简谐振荡。时间域热容：

$$
\rho C_p\frac{\partial\Delta}{\partial t}
$$

代入 $\Delta=\tilde{\Delta}\,e^{i2\omega t}$：

$$
\frac{\partial\Delta}{\partial t}=i2\omega\,\tilde{\Delta}\,e^{i2\omega t}
\quad\Rightarrow\quad
\rho C_p\frac{\partial\Delta}{\partial t}
\;\longrightarrow\;
i2\omega\,\rho C_p\,\tilde{\Delta}
$$

| 问题 | 答案 |
|------|------|
| 为何是 $2\omega$ 不是 $\omega$？ | 电流频率 $\omega$，功率 $\propto\sin^2\omega t$ 的交变分量是 **$2\omega$**，温度跟着抖 |
| $i$ 是什么？ | 相位：热容让温升**落后**于加热，用虚数写入复振幅 |
| 和 $m^2$？ | 除以 $\kappa$ 得 $i2\omega/\alpha$ 那一项；另一项才是辐射 |

**一句话**：不是另一种热容，只是 $\partial/\partial t\to i2\omega$。

## 3. 辐射是什么？$h_r$ 是什么？

### 3.1 不是「沿直径往芯里传热」

辐射项描述的是：丝的**侧面把热辐射到周围环境（腔壁）而散失**。

| 方向 | 模型怎么处理 |
|------|----------------|
| **轴向 $x$** | 导热主通道，两端 $\Delta=0$ |
| **径向（直径）** | 假定芯内径向温度近似均匀；**不用** $h_r$ 算「镀层→芯」导热 |
| **侧面 → 环境** | 真空中主要靠辐射散热 → $h_r$ |

绝缘丝：镀层表面焦耳发热；热主要由**纤维芯沿轴向**导走；侧表面同时向环境辐射——$h_r$ 只描述后者。

### 3.2 $h_r$ 的定义

线性化**辐射换热系数**，单位 $\mathrm{W/(m^2\cdot K)}$：

$$
h_r = 4\varepsilon\sigma T_0^3
$$

- $\varepsilon$：表面发射率  
- $\sigma$：Stefan–Boltzmann 常数  
- $T_0$：环境/热沉温度  

来源：净辐射 $\propto\varepsilon\sigma(T^4-T_0^4)$，小温升近似成 $h_r\cdot\Delta T$（类似对流 $h\Delta T$，这里的 $h$ 来自辐射故称 $h_r$）。

单位长度侧面散热 $\sim h_r\cdot(\pi D)\cdot\Delta$，写进体积方程后出现 $(4h_r/D)\tilde{\Delta}$。

### 3.3 导电要不要算辐射？

**不是不需要，而是常常可以先忽略。**

- Lu 主方程右边只写焦耳热，侧面辐射未写入主式。  
- 条件 **(31)**：$g\gamma\ll 1$ → 可忽略辐射。  
- 细长/高温/发射率大时，导电也开辐射：  
  $g=16\varepsilon\sigma T_0^3/(\rho C_p D)$ → $\kappa_{\mathrm{ap}},\gamma_{\mathrm{ap}}$。

| | 导电 | 绝缘 |
|--|------|------|
| 默认主公式 | 常先不算辐射 | 常把辐射写进方程 |
| 判据 | 看 $g\gamma\ll 1$ | 细长丝建议算 |
| 写法 | $g$ → 表观 $\kappa,\gamma$ | $h_r$ → $m^2$ |

绝缘细长丝若 $\varepsilon=0$（$h_r=0$），等于没开辐射，拟合 $\kappa$ 易偏高。

## 4. 导电右边电热 和 绝缘 $q'''_{2\omega}$ 是一回事吗？

**物理同源，写法不同：都是焦耳热；绝缘只取出 $2\omega$ 分量。**

导电右边：

$$
\frac{I_0^2\sin^2\omega t}{LS}\bigl[R+R'(T-T_0)\bigr]
$$

- 全时域单位体积功率  
- 含**直流 + $2\omega$**  
- 含 $R'\Delta$ 反馈（常线性化丢掉）

绝缘 $q'''_{2\omega}$：

- 同样来自 $I^2 R$  
- 方程只对 $2\omega$ 复振幅写 → 右端只留 **$2\omega$ 谐波**  
- 一般不再写入 $R'\Delta$ 反馈

关系示意：

$$
\underbrace{\text{导电全功率}(t)}_{\text{直流}+2\omega+\ldots}
\;\supset\;
\underbrace{q'''_{2\omega}\,e^{i2\omega t}}_{\text{只取 }2\omega\text{ 一块}}
$$

## 5. 一句话总表

| 问题 | 短答 |
|------|------|
| 两边方程骨架？ | 导热 + 热容 (±辐射) = 焦耳热 |
| 热容为何长得不同？ | 时域 ↔ 频域（$\partial_t\to i2\omega$） |
| 辐射是径向往芯传热吗？ | **不是**；是侧面→环境辐射损失 |
| $h_r$？ | $4\varepsilon\sigma T_0^3$，辐射等效换热系数 |
| 导电不算辐射？ | 常可忽略；需要时用 $g$ |
| 右边热源一样吗？ | 都是焦耳热；绝缘只取 $2\omega$ 分量 |
| 本质差别？ | 谁导电/参数归属 + 级数 vs $m$/$F(m)$，公式勿混用 |
