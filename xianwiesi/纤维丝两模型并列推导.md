## 1. 共同起点（尚未分叉）

### 1.1 几何与边界（两边相同）

悬空段长度 $L$（电压触点间距），两端接到高导热焊盘/热沉：

$$
\boxed{
T(0,t)=T(L,t)=T_0
\quad\Leftrightarrow\quad
\Delta(0)=\Delta(L)=0
}
$$

其中 $\Delta=T-T_0$。中间悬空段升温，热主要沿**轴向**流向两端。  
**绝缘丝并没有取消这条边界**；后面的 $\sinh/\cosh$ 解正是在这条边界下得到的。

### 1.2 3ω 信号链（两边相同）

1. 电流 $I\sim\sin\omega t$ → 焦耳功率 $\propto I^2$ 含 **直流 + $2\omega$**  
2. 温度：直流温升 + **$2\omega$ 波动**（热容使温升落后于功率）  
3. $\delta R=R'\,\Delta$ → 电压出现 **$3\omega$**  
4. 锁相测 $V_{3\omega}(f)$ → 反推 $\kappa$、$C_p$（或 $\alpha=\kappa/(\rho C_p)$）

### 1.3 从哪一步开始分叉

| 分叉点 | 导电丝 | 绝缘丝 |
|--------|--------|--------|
| 谁发热、谁测温 | **丝本体** | **表面镀金属**；芯不导电 |
| $R,R'$ 归属 | 纤维本身 | **镀层**（需退火 + $R(T)$ 标定） |
| $\kappa,\rho,C_p$ 归属 | 纤维本身 | **纤维芯** |
| 方程写法 | 时间域 PDE → 冲量响应 | 直接对 $2\omega$ 复振幅写 ODE |
| 空间解法 | 正弦级数 $\sin(n\pi x/L)$，常截断 $n=1$ | 闭式 $\sinh(mL)/\cosh$，传递函数 $F(m)$ |

```
共同：两端 Δ=0 + 焦耳热 + R' → V3ω
              │
     ┌────────┴────────┐
     ▼                 ▼
  导电：本体发热        绝缘：镀层发热（芯导热）
     │                 │
     ▼                 ▼
  时间域热方程          频域 2ω 方程（常含 hr）
  + 正弦级数 n          + 复波数 m
     │                 │
     ▼                 ▼
  截断 n=1 → γ         平均温升 → F(m)
     │                 │
     ▼                 ▼
  式(19)：1/√(1+(2ωγ)²)   V3 ∝ R' F(m)
```

## 2. 步骤对照：从热方程到 $V_3$

### 步骤 ① 样品结构

| 导电丝 | 绝缘丝 |
|--------|--------|
| 丝导电，本体既是加热器也是温度计 | 芯绝缘，镀薄金属（如 Au）作加热/温度计 |
| 一维：径向温度近似均匀 | 另加：镀层极薄 $t\ll D$，镀层热容/轴向导热可忽略；$\kappa$ 等取**芯**的 |

### 步骤 ② 写出热方程

**导电（时间域，论文式 1）**

$$
\rho C_p\frac{\partial T}{\partial t}-\kappa\frac{\partial^2 T}{\partial x^2}
=\frac{I_0^2\sin^2\omega t}{LS}\bigl[R+R'(T-T_0)\bigr]
$$

边界：$T(0)=T(L)=T_0$。右端含 $R'\Delta$ 反馈项，后面用条件 (10) 线性化丢掉。

**绝缘（$2\omega$ 复振幅，含径向辐射）**

侧表面辐射线性化：$h_r=4\varepsilon\sigma T_0^3$。对谐波 $\tilde{\Delta}(x)\,e^{i2\omega t}$：

$$
\kappa\frac{d^2\tilde{\Delta}}{dx^2}
-\Bigl(i2\omega\,\rho C_p+\frac{4h_r}{D}\Bigr)\tilde{\Delta}
=-q'''_{\,2\omega}
$$

整理为

$$
\frac{d^2\tilde{\Delta}}{dx^2}-m^2\tilde{\Delta}=-\frac{q'''_{\,2\omega}}{\kappa}
$$

$$
\boxed{
m^2=\frac{i2\omega}{\alpha}+\frac{4h_r}{D\kappa}
}
$$

边界：**同样** $\tilde{\Delta}(0)=\tilde{\Delta}(L)=0$。

> 两边都是轴向一维 + 两端热沉。差别在于：导电走时间域+模态；绝缘直接频域 ODE，并把辐射写进 $m^2$。

### 步骤 ③ 为什么一个是正弦级数、一个是双曲函数？

**同一边界 $\Delta(0)=\Delta(L)=0$，两种合法解法：**

| | 导电丝 | 绝缘丝 |
|--|--------|--------|
| 思路 | 把空间分布展成满足两端为 0 的完备基 | 常系数 ODE 的通解用指数/双曲函数，再用两端为 0 定系数 |
| 基/通解 | $\sin(n\pi x/L)$，$n=1,2,\ldots$ | $\sinh(mx),\cosh(mx)$（或等价指数） |
| 为何“看起来不同” | 级数截断后只剩 $n=1$，出现 $\gamma$ | 不解级数，一次写出闭式平均温升 $F(m)$ |

对导电丝，每个正弦模满足

$$
\alpha\Bigl(\frac{n\pi}{L}\Bigr)^2=\frac{n^2}{\gamma},\qquad
\gamma\equiv\frac{L^2}{\pi^2\alpha}
$$

$n^2/\gamma$ = 该空间模被「轴向导热 + 两端热沉」拉回平衡的速率。

对绝缘丝，ODE $\Delta''-m^2\Delta=\text{const}$ 在 $\Delta(0)=\Delta(L)=0$ 下的解，平均后自然出现 $\sinh(mL)$、$\cosh(mL)$——**这就是钳制边界的体现**，不是取消了焊盘条件。

### 步骤 ④ 线性化 / 简化假设

| 导电丝 | 绝缘丝 |
|--------|--------|
| 条件 (10)：$I_0^2|R'|L/(\pi^2\kappa S)\ll 1$ → 可忽略 $R'$ 反馈，各模独立指数衰减 | 小温升、恒流；镀层薄，不把镀层厚度写进 $V_3$ |
| 常用截断：只留 $n=1$（要求 $2\omega\gamma\lesssim 4$） | 径向近似均匀（细丝、频率不太高） |
| 辐射可选：$g\gamma\ll 1$ 可忽略；否则用表观 $\kappa_{\mathrm{ap}},\gamma_{\mathrm{ap}}$ | 细长丝**建议**把 $h_r$ 写入 $m^2$，否则 $\kappa$ 易偏高 |

### 步骤 ⑤ 得到平均温升 → $V_3$

**导电（截断 $n=1$，rms 实用式）**

$$
\boxed{
|V_{3\omega}|\approx
\frac{4\,I_{\mathrm{rms}}^3\,L\,R\,|R'|}
{\pi^4\kappa S\sqrt{1+(2\omega\gamma)^2}}
}
\qquad
\tan\varphi\approx 2\omega\gamma
$$

$$
\gamma=\frac{L^2}{\pi^2\alpha},\quad
C_p=\frac{\pi^2\gamma\kappa}{\rho L^2}
$$

**绝缘（均匀发热 + 两端为 0 → 传递因子 $F$）**

$$
F(m)=\frac{2-2\cosh(mL)+mL\sinh(mL)}{L^2 m^3\sinh(mL)}
$$

$$
\boxed{
V_3^{\mathrm{(amp)}}
=\frac{I_0^3 R_0 R'}{\kappa\,\pi D^2}\,F(m)
}
$$

（实现中 $I_0=\sqrt{2}I_{\mathrm{rms}}$，再除 $\sqrt{2}$ 得 rms，与实验一致。）

## 3. 低 / 高频极限（并列）

| | 导电丝 | 绝缘丝 |
|--|--------|--------|
| 尺子 | $2\omega\gamma$ | $|mL|$（或是否接近极限式） |
| **低频** → 主得 $\kappa$ | $2\omega\gamma\to 0$：幅值平台 $\propto 1/\kappa$ | $m\to 0$：$F\to L/12$，$V_3\propto L/(\kappa D^2)$ |
| **高频** → 主得 $C_p$ | $2\omega\gamma\to\infty$：$\propto 1/\omega$ | $|mL|\gg 1$（无辐射）：$\propto 1/(\omega\,\rho C_p)$ |
| 中间扫频 | 可同时拟合 $\kappa$ 与 $C_p$ | 用全频 $F(m)$ 同时拟合芯的 $\kappa$、$C_p$ |

绝缘低频极限（式 9）：

$$
V_3^{\mathrm{(amp)}}=\frac{I_0^3 R_0 R' L}{12\kappa\pi D^2}
$$

绝缘高频极限（式 10，无辐射）：

$$
V_3^{\mathrm{(amp)}}=\frac{I_0^3 R_0 R'}{i\,2\omega\,\rho C_p\pi D^2 L}
$$

## 4. 辐射：同一物理，嵌入位置不同

| | 导电丝 | 绝缘丝 |
|--|--------|--------|
| 系数 | $g=16\varepsilon\sigma T_0^3/(\rho C_p D)$ | $h_r=4\varepsilon\sigma T_0^3$，项 $4h_r/(D\kappa)$ |
| 进入方式 | 表观 $\kappa_{\mathrm{ap}}=(1+g\gamma)\kappa$，$\gamma_{\mathrm{ap}}=\gamma/(1+g\gamma)$ | 直接加进 $m^2$ |
| 建议 | $g\gamma\ll 1$ 可关；细长/高温再开 | 细长丝建议开；$\varepsilon=0$ 则 $h_r=0$（等于没开） |

二者圆柱辐射同源，只是 Lu 走时间域表观修正，绝缘走频域 $m^2$。

## 5. 相位与实验注意（并列）

| 点 | 说明 |
|----|------|
| 物理 | 两边都是：加热在前、温升滞后 → 频率越高相位越往正交靠 |
| 公式符号 | 当前代码里，同号 $R'$ 时导电与绝缘相位曲线可能差约 **180°**（约定问题），**不是**两种材料物理反向 |
| 接线 | 接法固定后相位正负就固定；与模型对齐一次即可 |
| 拟合 | 幅值定 $\kappa$ 的绝对尺度；相位/$γ$ 或高频定 $C_p$（或 $\alpha$）。详见简版实验说明 |

## 6. 一句话对照 + 勿混用

| 问题 | 答案 |
|------|------|
| 两端是否都钳 $\Delta=0$？ | **都是** |
| 为何一个正弦、一个双曲？ | **同一边界的两种解法**（级数截断 vs ODE 闭式） |
| 本质差别在哪？ | 谁导电/谁提供 $R,R'$，以及方程写成时间域模态还是频域 $m$ |
| 公式能混用吗？ | **不能**。导电数据勿套绝缘 $F(m)$，反之亦然 |
