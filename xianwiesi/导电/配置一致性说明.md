## 关键配置说明

### 1. 随机种子（已固定）

**run_fiber_simulation.py 第98行：**
```python
np.random.seed(42)  # 固定随机种子
```

**作用：** 确保每次生成的噪声相同，从而数据可重复。

---

### 2. 初值偏离（已启用）

**run_fiber_simulation.py 第110-111行：**
```python
initial_guess['kappa'] *= 1.2  # 偏离+20%
initial_guess['C_p'] *= 0.8    # 偏离-20%
```

**fit_fiber_data.py 第56行：**
```python
'enabled': True,  # 启用初值偏离
```

**作用：** 测试算法从错误初值收敛的能力，两边必须使用相同的偏离。

---

### 3. 频率筛选（已关闭）

**fit_fiber_data.py 第78行：**
```python
'use_range': False,  # 关闭筛选
```

**作用：** 使用全部数据点，与 run_fiber_simulation.py 一致。

---

### 4. 拟合模式选择

**run_fiber_simulation.py 第118行：**
```python
fit_modes = ['amplitude', 'phase', 'both']  # 测试3种模式
```

**fit_fiber_data.py 第66行：**
```python
'fit_mode': 'amplitude',  # 只选一种
```

**注意：** 必须选择相同的模式进行对比！

- `amplitude` - 仅拟合幅值（推荐用于高热导率材料）
- `phase` - 仅拟合相位（较少使用）
- `both` - 同时拟合实部和虚部（精度最高，但可能更慢）

## 故障排除

### 问题1：结果差异 > 1%

**可能原因：**
1. ❌ 初值偏离未启用
2. ❌ 拟合模式不同
3. ❌ 频率筛选未关闭
4. ❌ 数据文件不匹配（旧数据）

**解决方案：**
```bash
# 重新生成数据
python run_fiber_simulation.py

# 检查配置
# 确认 fit_fiber_data.py 顶部的配置说明
python fit_fiber_data.py
```

---

### 问题2：RMSE差异很大

**可能原因：**
1. ❌ 优化参数不同（max_iter, zeta）
2. ❌ 参数边界不同

**检查清单：**
```python
# 两个文件都应该是：
max_iter = 30
zeta = 0.5
kappa_bounds = (0.1, 5000)
C_p_bounds = (50, 2000)
```

---

### 问题3：迭代次数不同

**说明：** 这是正常的！

即使最终结果相同，不同的初值可能导致不同的迭代路径：
- run_fiber_simulation.py: 初值偏离 → 可能需要18次迭代
- fit_fiber_data.py: 读取数据后再偏离 → 可能需要16次迭代

**判断标准：** 看最终的 κ, Cp, RMSE 是否一致，而非迭代次数。

## 高级配置：实际数据分析

如果用于**实际实验数据**分析（而非验证算法），建议使用以下配置：

```python
# fit_fiber_data.py 推荐配置

MATERIAL_CONFIG = {
    'material_name': 'platinum',  # 使用材料库初值
    'perturb_initial': {
        'enabled': False,  # ← 关闭偏离，使用准确初值
    }
}

FITTING_CONFIG = {
    'fit_mode': 'both',  # ← 使用最高精度模式
    'param_bounds': {
        'kappa': (1, 5000),    # 根据材料调整
        'C_p': (50, 5000),     # 扩大边界
    },
    'optimization': {
        'max_iter': 100,   # ← 增加迭代次数
        'zeta': 0.3        # ← 降低步长提高稳定性
    },
    'frequency_range': {
        'use_range': True,  # ← 启用筛选
        'min_freq': 10,     # 去掉低频噪声
        'max_freq': 100,    # 去掉高频失效区
    }
}
```
