================================================================================
故障排除
================================================================================

【问题1】结果差异 > 1%

可能原因:
    ❌ 初值偏离未启用
    ❌ 拟合模式不同
    ❌ 数据文件不匹配

解决方案:
    1. 运行: python verify_consistency.py
    2. 检查 fit_fiber_data.py 第56行: 'enabled': True
    3. 检查 fit_fiber_data.py 第66行: 'fit_mode': 'amplitude'
    4. 重新生成数据: python run_fiber_simulation.py

【问题2】找不到数据文件

错误信息:
    错误: 未找到任何数据文件!

解决方案:
    1. 确认已运行: python run_fiber_simulation.py
    2. 检查文件名是否匹配
    3. 检查 fit_fiber_data.py 第38行的文件路径

【问题3】拟合不收敛

现象:
    达到最大迭代次数，RMSE很大

可能原因:
    ❌ 参数边界太小（尤其是碳纳米管）
    ❌ 初值太差

解决方案:
    1. 检查边界: kappa上限应≥5000（碳纳米管）
    2. 增加迭代次数: max_iter = 100
    3. 降低步长: zeta = 0.3

【问题4】迭代次数不同但结果相同

说明:
    ✅ 这是正常的！
    
    不同的数值路径可能导致不同的迭代次数，
    只要最终的 κ, Cp, RMSE 一致即可。

判断标准:
    - κ 差异 < 0.1%  ✅
    - Cp 差异 < 0.1% ✅
    - RMSE 相同      ✅
    - 迭代次数不同   ⚠️ 可忽略
