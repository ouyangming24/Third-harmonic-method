# 导电纤维 3ω vs 块体（平面）3ω

先把**导电纤维**讲清楚，再和主程序里的**块体/薄膜平面 3ω**对照。

---

## 一、导电纤维在测什么

一根**自身导电**、电阻随温度变（$R'\neq 0$）的丝：

- 四线法：外侧通电流，内侧测电压  
- **电压极之间悬空**，两端接点接到恒温热沉（$T=T_0$）  
- 丝**既是加热器又是温度计**

电流 $I\sim\sin\omega t$ → 焦耳热有直流 + **$2\omega$** → 温度波动 → 电阻波动 → 电压里出现 **$3\omega$**。  
扫频测 $V_{3\omega}(f)$，拟合得到丝的轴向 **$\kappa$**、**$C_p$**（或 $\alpha$）。

---

## 二、导电纤维：物理图像（重新说一遍）

### 1. 边界

$$
T(0)=T(L)=T_0
\quad\Rightarrow\quad
\text{两端不升温，中间升温}
$$

热主要沿**丝长方向（轴向 $x$）**流到两端热沉，不是往“厚度方向”钻。

### 2. 为什么能同时得到 κ 和 Cp

特征时间：

$$
\gamma=\frac{L^2}{\pi^2\alpha},\qquad\alpha=\frac{\kappa}{\rho C_p}
$$

无量纲频率：$2\omega\gamma$（热在 $2\omega$）。

| 频段 | $2\omega\gamma$ | 物理 | 主要得到 |
|------|-----------------|------|----------|
| 低频 | $\lesssim 0.1$（约小 10 倍） | 整段准静态，热跟得上 | **κ**（幅值平台） |
| 中间 | $\sim 1\sim 4$ | 部分跟得上 | κ 与 Cp 都有信息 |
| 高频 | $\gtrsim 10$（约大 10 倍） | 来不及传到两端 | **Cp**（$\propto 1/\omega$） |

实用幅值（rms，Lu 式 19）：

$$
|V_{3\omega}|\approx
\frac{4I_{\mathrm{rms}}^3 L R |R'|}{\pi^4\kappa S\sqrt{1+(2\omega\gamma)^2}}
$$

相位滞后大致：$\tan\varphi\approx 2\omega\gamma$（热容+导热造成温升落后于加热）。

### 3. 参数都是“这一根丝”

$R$、$R'$、$\kappa$、$\rho$、$C_p$、$S$（或 $D$）全部属于**纤维本体**——和绝缘镀层那种“电归镀层、热归芯”不同。

### 4. 关键假设（要心里有数）

| 条件 | 含义 |
|------|------|
| 两端 $\Delta T=0$ | 热沉够好（工艺保证） |
| 条件 (10) | 电流别太大，线性化成立 |
| 条件 (31) | 辐射可忽略，或做表观修正 |
| $2\omega\gamma\lesssim 4$ | 单模公式好用 |

直流中心温升量级也含 **κ**：

$$
\Delta_0\sim\frac{2I_0^2 R L}{\pi\kappa S}
$$

所以即使用 $I$、$R$、尺寸，**正演温升仍要 κ**；也可用 $R'$ 从电阻变化**测**温升。

## 三、块体 / 薄膜平面 3ω（主程序 Olson）在测什么

典型结构：

- 样品表面有一条**金属加热器兼温度计**  
- 下面是薄膜 + **衬底（半无限或很厚）**  
- 热主要往**法向 $z$**（厚度方向）传入衬底  

锁相测加热器的 $V_{3\omega}$ → 换成交流温升 $\Delta T(f)$ → 用多层热扩散模型（Olson 等）拟合膜/衬底的热物性。

常用判据（穿透深度 $\delta=\sqrt{\alpha/(4\pi f)}$）：

- **半无限**：基底厚度 $H\gtrsim 5\delta$  
- 斜率法还有：$\delta$ 相对加热器半宽等条件

## 四、并列对比（导电纤维 vs 块体）

| 项目 | 导电纤维 (Lu) | 块体/膜 (Olson 平面) |
|------|---------------|----------------------|
| **样品形态** | 悬空细丝/棒 | 平面多层 + 表面线热源 |
| **谁加热/测温** | **丝本体** | **表面金属条** |
| **主传热方向** | **轴向 $x$**（到两端） | **法向 $z$**（进衬底） |
| **“温升≈0”在哪** | 丝的**两端** $x=0,L$ | 深处 $z\to\infty$（或足够厚的底） |
| **几何特征长度** | 悬空长度 $L$ | 穿透深度 $\delta$、厚度 $H$、半宽 $b$ |
| **低频/高频尺子** | $2\omega\gamma$ 相对 1（$\gamma=L^2/\pi^2\alpha$） | $\delta$ 相对 $H$、$b$ |
| **半无限类条件** | 无“$L>5\lambda$”那种；两端靠热沉 | 常用 $H\gtrsim 5\delta$ |
| **得到什么** | 丝的轴向 κ、Cp | 膜/衬底（常为法向）热物性 |
| **代码** | `lu2001_fiber_model.py` / 纤维 GUI | `thermal_measurement_gui2.py` + Olson |

### 相同点（为什么都叫 3ω）

1. 交流电加热 → $2\omega$ 温升 → $R'$ → **$3\omega$ 电压**  
2. 用电学测交流温升（或等价 $V_{3\omega}$）  
3. 和**热扩散模型**拟合，得到热物性  

### 不同点（为什么公式不能混用）

1. **热往哪流**：丝是两端拉走；块体是往下钻进衬底  
2. **边界**：丝是有限长 + 两端恒温；块体常是半无限基底  
3. **传感器**：丝是自己；块体是镀在表面的线

## 六、关键传热推导对照（块体你熟的那条 → 导电纤维）

你熟悉的块体路径可以概括成：

> 傅里叶定律 → 能量守恒 → 热方程 →（以半宽 $b$ 等）做**空间傅里叶积分** → 加热器平均温升 $\Delta T(2\omega)$ → 用电学 $V_{3\omega}\leftrightarrow\Delta T$

导电纤维**前两步完全一样**，后面“怎么变换、怎么和电学对接”换成有限长丝的一套。

### 步骤对照表

| 步骤 | 块体（平面 3ω） | 导电纤维（Lu） |
|------|----------------|----------------|
| **① 傅里叶定律** | $\mathbf{q}=-\kappa\nabla T$（常含各向异性） | 同一条：$q_x=-\kappa\partial_x T$（只留轴向） |
| **② 能量守恒** | $\rho C_p\partial_t T=-\nabla\cdot\mathbf{q}+$源 | 同一条；源 = 单位体积焦耳热 |
| **③ 得到热方程** | 衬底/膜中的扩散方程 | $\rho C_p\partial_t T-\kappa\partial_x^2 T=\dfrac{I_0^2\sin^2\omega t}{LS}[R+R'\Delta]$ |
| **④ 几何与边界** | 表面线热源宽 $2b$；半无限或多层 $z$ | 有限长 $[0,L]$；$T(0)=T(L)=T_0$ |
| **⑤ 空间变换** | **连续**傅里叶变换（波数 $k$ 或 $\lambda$），加热器形状 $\sim\sin(kb)/(kb)$ 等 | **离散**正弦级数 $\sin(n\pi x/L)$（因两端为 0，不是无限域 FT） |
| **⑥ 频率** | 热在 $2\omega$，穿透深度 $\delta(f)$ | 热在 $2\omega$；特征时间 $\gamma=L^2/(\pi^2\alpha)$，无量纲 $2\omega\gamma$ |
| **⑦ 得到温升** | 加热器下（或平均）$\Delta T(2\omega)$ | 各模叠加得 $\Delta(x,t)$；再对长度积分 |
| **⑧ 接到电学** | $\delta R=R'\overline{\Delta T}$，$V_{3\omega}\propto I\cdot\delta R$ | **完全同一逻辑**：$\delta R=\dfrac{R'}{L}\int_0^L\Delta\,dx$，再 $\times I$ 得 $V_{3\omega}$ |

### 对应关系（帮你记）

| 块体里的角色 | 纤维里的角色 |
|--------------|--------------|
| 半宽 $b$（加热器横向尺度） | 长度 $L$（两端热沉间距） |
| 连续波数 $k$ 的积分 | 模态编号 $n=1,3,5,\ldots$ 的求和 |
| 半无限 $z$ / 多层传递矩阵 | 两端 Dirichlet → 正弦本征函数 |
| $\Delta T_{\mathrm{heater}}(f)$ | $\overline{\Delta T}(f)$（电阻加权平均温升） |
| $V_{3\omega}\leftrightarrow\Delta T$ | **同一套** $R'$、$I$ 关系 |

### 纤维侧把链条写短（只留关键）

**1）傅里叶 + 能量 → 一维热方程**（与块体同起点）

$$
\rho C_p\frac{\partial\Delta}{\partial t}-\kappa\frac{\partial^2\Delta}{\partial x^2}
=\frac{I_0^2\sin^2\omega t}{LS}\bigl[R+R'\Delta\bigr]
$$

**2）边界迫使“正弦展开”，不是带 $b$ 的连续 FT**

$$
\Delta(0)=\Delta(L)=0
\quad\Rightarrow\quad
\Delta(x,t)=\sum_{n=1}^{\infty}U_n(t)\sin\frac{n\pi x}{L}
$$

（块体用 $b$，是因为加热器在**无限大平面**上有有限宽度；纤维用 $L$，是因为定义域**有限**且两端钉死。）

**3）线性化（条件 10）后，模衰减率 $\propto n^2/\gamma$**

$$
\gamma=\frac{L^2}{\pi^2\alpha}
$$

只留 $n=1$ → 出现 $\sqrt{1+(2\omega\gamma)^2}$ 那条幅值式。

**4）和电学对接（与块体同构）**

$$
\delta R=\frac{R'}{L}\int_0^L\Delta(x,t)\,dx
\quad\Rightarrow\quad
V_{3\omega}\sim I\cdot\delta R
$$

块体是“对加热器宽度平均温升”；纤维是“对悬空段长度平均温升”。  
之后都是：锁相测到的 $V_{3\omega}$ ↔ 模型算出的 $\Delta T$（或直接拟合 $V_{3\omega}$ 公式）。

### 一句话对应

- 块体：傅里叶定律 + 能量守恒 → **横向连续 FT（含 $b$）** → 加热器 $\Delta T$ → $V_{3\omega}$。  
- 导电纤维：同一傅里叶定律 + 能量守恒 → **轴向离散正弦级数（含 $L$）** → 整段平均 $\Delta T$ → **同样的** $V_{3\omega}\leftrightarrow\Delta T$。  

差别不在“电学怎么接温升”，而在**热方程在什么几何里、用连续 FT 还是离散模态求解**。
